# Focus ring: subtle, keyboard-only (#1723) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The focus ring reads as a hint, not a border: a 1px accent ring at reduced opacity on fine-pointer devices, no ring on coarse-pointer devices, and never one on the CDK dialog container.

**Architecture:** One global rule in `styles/_base.scss` owns the ring, as today; a `(pointer: coarse)` media block removes it where no keyboard exists; `styles.scss`'s overlay block gives `cdk-dialog-container` `outline: none`, since focus parked there (WebKit never moves programmatic focus on to a button) is an implementation detail.

**Tech Stack:** SCSS with theme tokens, Stylelint.

**Spec:** GitHub issue #1723. Decision taken with the user in chat: subtle keyboard-only ring, not removal.

## Global Constraints

- No hex colours; the ring colour is `color-mix` over `--accent`.
- `_controls.scss` keeps trading the outline for an accent border on bordered inputs; that rule outranks the base ring and is untouched.
- Commits: `fix(#1723): …`, no attribution lines.

### Task 1: The ring

**Files:**
- Modify: `frontend/src/styles/_base.scss` (the `:focus-visible` rule)
- Modify: `frontend/src/styles.scss` (the overlay block)
- Modify: `docs/design-language.md` (the focus-outline paragraph in the Forms section)

- [ ] **Step 1: Change the rule**

```scss
:focus-visible {
  outline: 1px solid color-mix(in srgb, var(--accent) 60%, transparent);
  outline-offset: 0;
}

/* Focus on a touch device is programmatic, never a keyboard: no ring to show. */
@media (pointer: coarse) {
  :focus-visible {
    outline: none;
  }
}
```

In `styles.scss`, next to the overlay-pane rules:

```scss
// WebKit leaves a dialog's initial focus on the container; a ring there outlines the whole sheet.
cdk-dialog-container {
  outline: none;
}
```
