## Global Constraints

- **Paths and commands are relative to the repository root**, except the `docker compose exec -T frontend …` commands, which run inside the container's `/app` (`frontend/`).
- **Read before you write.** Every edit names its file and the exact Before. Apply it with the Edit tool (exact string replacement: the whole Before, replaced by the whole After). If the Before is not in the file exactly once, stop and report the file, the edit and the text you found. Change nothing else: no reflow, no restyling, no other line.
- **Per task, exactly this:** apply the task's edits in order, run the task's check step (its grep, which must print nothing, and its positive controls), then `git add` the paths the step names and commit with the message it gives. Nothing else runs per task.
- **Stage only the named paths.** Never `git add -A`, `git add .` or `git commit -a`.
- **Commits:** `docs(#1258): …`, one per task, exactly as each task gives it; the first commit is `docs(#1258): the plan`. No attribution lines.
- **Branch:** `docs/1258-spec-refresh`, cut from an up-to-date `origin/develop` (Task 0).
- **PR body:** `Closes #1258`. One PR.
- **No PHP file changes.** So no PHPUnit, PHPStan, PHPMD, phptramp or Infection run; Task 5 proves the diff holds no `*.php`.
- **No reviewer subagent and no /simplify.** Every edit carries its evidence, and every Before was checked in plan order before the plan was sent.
- **Greps:** `grep -E` or `git grep -E`, never `-F` with backslashes. Every removal grep has a positive control: the same pattern on the file at `5706a310` (`git show 5706a310:<file> | grep -c -E …`) prints a known count, and the new text is counted after the edit.
- **Scratch files** live in `backend/var/spec-refresh-1258/` (ignored by `backend/.gitignore`'s `/var/`); nothing there is committed.
- **Frontend commands run in the Docker frontend container**, never natively: `docker compose exec -T frontend …`, one at a time.
- **The checkout is shared.** Run `git status --short && git branch --show-current` before any `checkout`, `switch`, `reset` or `stash`; another session may be mid-edit. Work in place, no worktrees.
- **Every command runs in the foreground.** No background jobs, no `&`, no `sleep`/`until` poll loops; the one watch is the merge step's single Monitor command.
- **Merge:** watch with the Monitor tool, one command: `gh pr checks <PR> --watch --fail-fast`. When it exits 0, `gh pr merge <PR> --merge`. Never `--auto`.

# Appendix L — `backend/var/spec-refresh-1258/check-links.py`

Uncommitted scratch (Step 0.4 writes it; `backend/var/` is ignored). Run from the repository root. It was run on a copy of `cf89c356` before and after every edit of this plan: 117 links before, 125 after, and 50 anchor references, all resolving.

```python
#!/usr/bin/env python3
"""Link check for #1258. Run from the repository root.

  check-links.py <file.md>...   every relative link and #anchor in these Markdown files resolves
  check-links.py --refs         every docs/<path>.md#<anchor> in the text on stdin resolves

Prints `OK <n>` (n = links or references checked), or one `BROKEN <where> <target>` line per failure
and exits 1. Anchors follow GitHub's heading slugs (lower case, punctuation dropped, spaces to
hyphens, -1/-2 for repeats), plus any id="…" or name="…" attribute in the file.
"""
import os
import re
import sys
from urllib.parse import unquote

FENCE = re.compile(r'^\s*(`{3,}|~{3,})')
HEADING = re.compile(r'^(#{1,6})\s+(.*?)\s*#*\s*$')
INLINE_CODE = re.compile(r'(`+)(.+?)\1')
LINK = re.compile(r'!?\[(?:[^\]\\]|\\.)*\]\(\s*<?([^()\s>]+(?:\([^()\s]*\))?[^()\s>]*)>?(?:\s+"[^"]*")?\s*\)')
DEFINITION = re.compile(r'^\s{0,3}\[[^\]]+\]:\s*<?(\S+?)>?(?:\s+"[^"]*")?\s*$')
HTML_ANCHOR = re.compile(r'\b(?:id|name)="([^"]+)"')
REFERENCE = re.compile(r'(docs/[a-z/.-]+\.md)#([A-Za-z0-9_-]+)')
EXTERNAL = re.compile(r'^(?:[a-z][a-z0-9+.-]*:|//)', re.IGNORECASE)


def prose_lines(path):
    """Yield (line_number, line) outside fenced code blocks."""
    fence = None
    with open(path, encoding='utf-8') as handle:
        for number, line in enumerate(handle, start=1):
            line = line.rstrip('\n')
            opening = FENCE.match(line)
            if fence is None and opening:
                fence = opening.group(1)[0] * len(opening.group(1))
                continue
            if fence is not None:
                if line.strip().startswith(fence) and line.strip().strip(fence[0]) == '':
                    fence = None
                continue
            yield number, line


def slug(text):
    text = re.sub(r'!?\[([^\]]*)\]\([^)]*\)', r'\1', text)
    text = text.replace('`', '').replace('*', '')
    text = re.sub(r'<[^>]+>', '', text)
    text = text.strip().lower()
    text = re.sub(r'[^\w\- ]', '', text)
    return text.replace(' ', '-')


_anchor_cache = {}


def anchors(path):
    if path not in _anchor_cache:
        found = set()
        seen = {}
        for _, line in prose_lines(path):
            heading = HEADING.match(line)
            if heading:
                base = slug(heading.group(2))
                count = seen.get(base, 0)
                found.add(base if count == 0 else '%s-%d' % (base, count))
                seen[base] = count + 1
            found.update(HTML_ANCHOR.findall(line))
        _anchor_cache[path] = found
    return _anchor_cache[path]


def check_target(source, target):
    """Return None when `target`, a link written in `source`, resolves; else a reason."""
    target = target.split('?', 1)[0]
    path_part, _, anchor = target.partition('#')
    path_part = unquote(path_part)
    resolved = source if path_part == '' else os.path.normpath(os.path.join(os.path.dirname(source), path_part))
    if not os.path.exists(resolved):
        return 'missing file'
    if anchor and resolved.endswith('.md') and unquote(anchor) not in anchors(resolved):
        return 'missing anchor'
    return None


def check_files(paths):
    checked = 0
    broken = []
    for path in paths:
        for number, line in prose_lines(path):
            line = INLINE_CODE.sub('', line)
            targets = LINK.findall(line)
            definition = DEFINITION.match(line)
            if definition:
                targets.append(definition.group(1))
            for target in targets:
                if EXTERNAL.match(target):
                    continue
                checked += 1
                reason = check_target(path, target)
                if reason:
                    broken.append('BROKEN %s:%d %s (%s)' % (path, number, target, reason))
    return checked, broken


def check_references(text):
    checked = 0
    broken = []
    for line in text.splitlines():
        for path, anchor in REFERENCE.findall(line):
            checked += 1
            if not os.path.isfile(path):
                broken.append('BROKEN %s %s#%s (missing file)' % (line.split(':', 1)[0], path, anchor))
            elif anchor not in anchors(path):
                broken.append('BROKEN %s %s#%s (missing anchor)' % (line.split(':', 1)[0], path, anchor))
    return checked, broken


def main(arguments):
    if arguments == ['--refs']:
        checked, broken = check_references(sys.stdin.read())
    elif arguments and '--refs' not in arguments:
        checked, broken = check_files(arguments)
    else:
        sys.stderr.write(__doc__)
        return 2
    for line in broken:
        print(line)
    if broken:
        return 1
    print('OK %d' % checked)
    return 0


if __name__ == '__main__':
    sys.exit(main(sys.argv[1:]))
```
