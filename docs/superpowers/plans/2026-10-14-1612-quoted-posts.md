# #1612 Quoted posts as nested, playable quote cards — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A post that quotes another post becomes a `quote` share: the quoted post is stored structured on the entry
(author, time, full text, media, nested-quote reference) and shown nested — a playable quote card in the magazine and
the reader view.

**Architecture:** Both networks build one carrier value, `App\Entity\QuotedPostContent`, gated by
`LinkCard\Support\StorableQuotedPost` and stored in a new embeddable `EntryQuotedPost` on `Entry`. Bluesky reads it
from the AppView's `viewRecord` (`Bluesky\Support\QuotedViewRecord`); Mastodon reads native quotes off the timeline
(`Social\Support\MastodonQuotedStatus`, carried by `KnownSharesModel`) and looks up "RE:" targets in the link-card worker
through a `LinkCard`-owned `QuotedPostSourceInterface` that `Social` implements. `EntryJson` serves it as `quote`; the
SPA renders it through one shared `app-quoted-post`, which reuses a `app-post-media` grid extracted from the media block.

**Tech Stack:** Symfony 7.4 / PHP 8.4 / Doctrine (MySQL + SQLite), Angular 20 standalone + signals, Jest, hls.js.

**Spec:** `docs/superpowers/specs/2026-10-14-1612-quoted-posts-design.md` — read it before any task. Mockup:
https://claude.ai/artifact/AZuifoj4FDLTSBQ1V738yk.

## Global Constraints

- New entries only; no backfill. Entry 594781 (subscription 1818) stays a link card.
- Quoted text cap: 3000 characters, cut at a word boundary (`WordBoundary::clipped`). Not `StorableLinkCard`'s 300.
- Clamps in the magazine: own text 6 lines (`card-states(6)`), quoted text 8 lines; the reader view clamps nothing.
- One nesting level: a quote inside the quoted post is one line, "Quoting a post by @handle", linking to it.
- An unavailable quote keeps today's behaviour (link card, or "View embedded content on Bluesky").
- A rendered quote upgrades a `Link` share to `Quote`; it never makes a non-share a share.
- The quote's media never enter the entry's own `media` list; the outer lead image never falls back to the quote's.
- Datetimes stored as naive UTC; normalise before persisting.
- iOS-viable JSON: plain fields, no HTML.
- No hex, no ad-hoc px, no media-query literals in `.scss`; styles in sibling `.scss`.
- Every touched `src` file PHPMD-clean; `composer check`, `composer md`, both PHPUnit legs, `composer infection:diff`,
  `npm run check` (frontend container) green. Migration verified on SQLite and MySQL.
- Commits: `type(#1612): lower-case summary`. No Claude attribution anywhere.

## Deviations from the spec (decided while planning — confirm or overrule at plan review)

1. **The magazine block kind is `quoting`, not `quote`.** `quote` is already a template kind (the pull-quote block,
   `blocks/entry-quote/`, `BLOCK_HEIGHT.quote = 180`). The API's `share` value stays `'quote'`; only the block kind and
   its folder differ: `blocks/entry-quoting/`, `app-entry-quoting`, `sharesQuotedPost()`.
2. **The embeddable is `EntryQuotedPost`** (every embeddable on `Entry` is `Entry*`); the carrier is
   `QuotedPostContent`, its nested reference `QuotedPostReference`.
3. **`nestedQuote.handle` is nullable.** Mastodon answers a quote's own quote shallow (`quoted_status_id` only), so its
   handle is unknown; the line then reads "Quoting a post". Bluesky always has it.
4. **The nested box is a stretched link, not an `<a>` around everything.** A `<video controls>` inside an `<a>` is
   invalid HTML and a click on its controls still activates the link (`stopPropagation` does not cancel a default
   action). The header's `<a class="open">` carries an `::after` that covers the box; videos and the nested-quote line
   sit above it (`z-index: 1`). Clicking an image or the text still opens the quoted post — the agreed behaviour.
5. **No cinema toggle on the quoted video.** `addCinemaToggles` re-parents DOM nodes, which is unsafe on
   Angular-rendered nodes, and widening a player out of its bordered box breaks the card. `playsinline` and HLS do
   apply. Say so if you want cinema there anyway (it would need a component-side toggle).
6. **Backups carry the quote.** `BackupLines` exports `shareKind`, so a restore would otherwise hold `share: quote`
   with no quote. Added as Task 6.
7. **A quote share does not await cards for other links in its text.** Those stay inline links (Mastodon native path).
   Bluesky's existing `AwaitingLinkCards` outcome is kept as it is.

```php
/** The post an entry quotes, stamped and read together; no url is the "quotes nothing" case. */
#[ORM\Embeddable]
final class EntryQuotedPost
{
    #[ORM\Column(name: 'quoted_url', length: QuotedPostContent::URL_MAX, nullable: true)]
    private ?string $url = null;

    #[ORM\Column(name: 'quoted_author_name', length: QuotedPostContent::NAME_MAX, nullable: true)]
    private ?string $authorName = null;

    #[ORM\Column(name: 'quoted_author_handle', length: QuotedPostContent::NAME_MAX, nullable: true)]

    #[ORM\Column(name: 'quoted_author_avatar_url', length: QuotedPostContent::URL_MAX, nullable: true)]
    private ?string $authorAvatarUrl = null;

    #[ORM\Column(name: 'quoted_posted_at', type: Types::DATETIME_IMMUTABLE, nullable: true)]
    private ?\DateTimeImmutable $postedAt = null;

    #[ORM\Column(name: 'quoted_text', type: Types::TEXT, nullable: true)]
    private ?string $text = null;

    /** @var list<array<string, mixed>>|null */
    #[ORM\Column(name: 'quoted_media', type: Types::JSON, nullable: true)]
    private ?array $media = null;

    #[ORM\Column(name: 'quoted_nested_url', length: QuotedPostContent::URL_MAX, nullable: true)]
    private ?string $nestedUrl = null;

    #[ORM\Column(name: 'quoted_nested_handle', length: QuotedPostContent::NAME_MAX, nullable: true)]
    private ?string $nestedHandle = null;

    public function store(QuotedPostContent $quote): void
    {
        $this->url = $quote->url;
        $this->authorName = $quote->authorName;
        $this->authorHandle = $quote->authorHandle;
        $this->authorAvatarUrl = $quote->authorAvatarUrl;
        $this->postedAt = $quote->postedAt;
        $this->text = $quote->text;
        $this->media = StoredList::orNull(EntryMedia::toJsonList($quote->media));
        $this->nestedUrl = $quote->nestedQuote?->url;
        $this->nestedHandle = $quote->nestedQuote?->handle;
    }

    public function read(): ?QuotedPostContent
    {
        if ($this->url === null || $this->authorName === null || $this->authorHandle === null) {
            return null;
        }

        return new QuotedPostContent(
            $this->url,
            $this->authorName,
            $this->authorHandle,
            $this->authorAvatarUrl,
            $this->postedAt,
            $this->text ?? '',
            StoredList::read($this->media, EntryMedium::isComplete(...), EntryMedium::fromStored(...)),
            $this->nestedUrl === null ? null : new QuotedPostReference($this->nestedUrl, $this->nestedHandle),
        );
    }
}
```

`backend/src/Service/LinkCard/Support/StorableQuotedPost.php`:

```php
<?php

declare(strict_types=1);

namespace App\Service\LinkCard\Support;

use App\Entity\EntryMedium;
use App\Entity\QuotedPostContent;
use App\Entity\QuotedPostReference;
use App\Service\Text\Support\WordBoundary;
use App\Service\Url\Support\AbsoluteHttpUrl;
use App\Service\Url\Support\HttpsImageUrl;

/**
 * A quoted post as an entry may hold it, whichever network or file it came from: none without a web address that
 * fits or without a handle; the rest cut to its columns.
 */
final class StorableQuotedPost
{
    public static function of(QuotedPostContent $quote): ?QuotedPostContent
    {
        $handle = mb_substr(trim($quote->authorHandle), 0, QuotedPostContent::NAME_MAX);
        if (!self::isWebPage($quote->url) || $handle === '') {
            return null;
        }
        $name = mb_substr(trim($quote->authorName), 0, QuotedPostContent::NAME_MAX);

        return new QuotedPostContent(
            $quote->url,
            $name === '' ? $handle : $name,
            $handle,
            self::fits((string) $quote->authorAvatarUrl) ? HttpsImageUrl::orNull($quote->authorAvatarUrl) : null,
            $quote->postedAt?->setTimezone(new \DateTimeZone('UTC')),
            WordBoundary::clipped($quote->text, QuotedPostContent::TEXT_MAX),
            self::storableMedia($quote->media),
            self::storableReference($quote->nestedQuote),
        );
    }

    /**
     * @param list<EntryMedium> $media
     *
     * @return list<EntryMedium>
     */
    private static function storableMedia(array $media): array
    {
        $https = array_filter($media, static fn (EntryMedium $medium): bool => HttpsImageUrl::orNull($medium->url) === $medium->url);

        return \array_slice(array_values($https), 0, QuotedPostContent::MEDIA_MAX);
    }

    private static function storableReference(?QuotedPostReference $reference): ?QuotedPostReference
    {
        if ($reference === null || !self::isWebPage($reference->url)) {
            return null;
        }
        $handle = $reference->handle === null ? '' : mb_substr(trim($reference->handle), 0, QuotedPostContent::NAME_MAX);

        return new QuotedPostReference($reference->url, $handle === '' ? null : $handle);
    }

    private static function isWebPage(string $url): bool
    {
        return self::fits($url) && AbsoluteHttpUrl::matches($url);
    }

    private static function fits(string $url): bool
    {
        return mb_strlen($url) <= QuotedPostContent::URL_MAX;
    }

    private function __construct()
    {
    }
}
```

```php
<?php

declare(strict_types=1);

namespace App\Service\Bluesky\Support;

use App\Entity\EntryMedium;
use App\Entity\QuotedPostContent;
use App\Entity\QuotedPostReference;
use App\Service\Bluesky\Model\JsonNodeModel;
use App\Service\Ingest\Support\EntryMediaAssembler;
use App\Service\LinkCard\Support\StorableQuotedPost;
use App\Service\Parser\Model\ParsedMediumModel;
use App\Service\Parser\Model\VisualMediaKind;
use App\Service\Parser\Support\DateParser;

/** The post a Bluesky post quotes, as the AppView's `record#viewRecord` gives it; none for a gone or hidden one. */
final class QuotedViewRecord
{
    private const string VIEW_RECORD = 'app.bsky.embed.record#viewRecord';
    private const string POST_RECORD = 'app.bsky.feed.post';
    private const string IMAGES = 'app.bsky.embed.images#view';
    private const string VIDEO = 'app.bsky.embed.video#view';
    private const string RECORD = 'app.bsky.embed.record#view';
    private const string RECORD_WITH_MEDIA = 'app.bsky.embed.recordWithMedia#view';

    public static function of(JsonNodeModel $record): ?QuotedPostContent
    {
        $value = $record->node('value');
        $url = AtPostUri::webUrl($record->string('uri') ?? '');
        $author = $record->node('author');
        $handle = $author->string('handle');
        if ($record->type() !== self::VIEW_RECORD || $value->type() !== self::POST_RECORD || $url === null || $handle === null) {
            return null;
        }
        $embed = $record->first('embeds');

        return StorableQuotedPost::of(new QuotedPostContent(
            $url,
            $author->string('displayName') ?? $handle,
            $handle,
            $author->string('avatar'),
            DateParser::parse($value->string('createdAt') ?? $record->string('indexedAt')),
            $value->text('text') ?? '',
            EntryMediaAssembler::assemble(null, self::mediaOf($embed), [])->media,
            self::nestedQuoteOf($embed),
        ));
    }

    /** @return list<ParsedMediumModel> */
    private static function mediaOf(JsonNodeModel $embed): array
    {
        return match ($embed->type()) {
            self::IMAGES => self::images($embed),
            self::VIDEO => self::video($embed),
            self::RECORD_WITH_MEDIA => self::mediaOf($embed->node('media')),
            default => [],
        };
    }

    /** @return list<ParsedMediumModel> */
    private static function images(JsonNodeModel $embed): array
    {
        $media = [];
        foreach ($embed->nodes('images') as $image) {
            $url = $image->string('fullsize');
            $ratio = $image->node('aspectRatio');
            if ($url !== null) {
                $media[] = new ParsedMediumModel($url, VisualMediaKind::Image, $ratio->int('width'), $ratio->int('height'));
            }
        }

        return $media;
    }

    /** @return list<ParsedMediumModel> */
    private static function video(JsonNodeModel $embed): array
    {
        $playlist = $embed->string('playlist');
        $ratio = $embed->node('aspectRatio');

        return $playlist === null ? [] : [new ParsedMediumModel(
            $playlist,
            VisualMediaKind::Video,
            $ratio->int('width'),
            $ratio->int('height'),
            $embed->string('thumbnail'),
        )];
    }

    private static function nestedQuoteOf(JsonNodeModel $embed): ?QuotedPostReference
    {
        $nested = match ($embed->type()) {
            self::RECORD => $embed->node('record'),
            self::RECORD_WITH_MEDIA => $embed->node('record')->node('record'),
            default => null,
        };
        $url = $nested === null ? null : AtPostUri::webUrl($nested->string('uri') ?? '');

        return $url === null ? null : new QuotedPostReference($url, $nested?->node('author')->string('handle'));
    }

    private function __construct()
    {
    }
}
```

```php
    /** A status's `quote`: only an accepted one with the whole status counts; a shallow one names an id alone. */
    public static function ofQuote(JsonNodeModel $quote): ?QuotedPostContent
    {
        return $quote->string('state') === self::ACCEPTED ? self::of($quote->node('quoted_status')) : null;
    }

    public static function of(JsonNodeModel $status): ?QuotedPostContent
    {
        $url = AbsoluteHttpUrl::orNull($status->string('url')) ?? AbsoluteHttpUrl::orNull($status->string('uri'));
        $account = $status->node('account');
        $handle = self::handleOf($account);
        if ($url === null || $handle === null) {
            return null;
        }
        $content = $status->string('content') ?? '';
        $quoted = QuoteLine::targetIn($content);

        return StorableQuotedPost::of(new QuotedPostContent(
            $url,
            $account->string('display_name') ?? $handle,
            $handle,
            $account->string('avatar'),
            DateParser::parse($status->string('created_at')),
            self::textOf($quoted === null ? $content : QuoteLine::removedFrom($content, $quoted), $status->string('spoiler_text')),
            EntryMediaAssembler::assemble(null, MastodonAttachments::of($status->nodes('media_attachments')), [])->media,
            self::nestedOf($status->node('quote'), $quoted),
        ));

    /** A local account's acct is the bare user name: the profile's host completes it. */
    private static function handleOf(JsonNodeModel $account): ?string
    {
        $acct = $account->string('acct');
        $host = parse_url((string) $account->string('url'), \PHP_URL_HOST);
        if ($acct === null || str_contains($acct, '@') || !\is_string($host)) {
            return $acct;
        }

        return $acct . '@' . $host;
    }

    private static function textOf(string $html, ?string $warning): string
    {
        $lines = PlainText::linesFromHtmlBlocks($html);

        return implode("\n", $warning === null ? $lines : ['CW: ' . $warning, ...$lines]);
    }

    private static function nestedOf(JsonNodeModel $quote, ?string $reTarget): ?QuotedPostReference

        if ($full !== null) {
            return new QuotedPostReference($full->url, $full->authorHandle);
        }

        return $reTarget === null ? null : new QuotedPostReference($reTarget, null);
    }
```

```ts
import { EntryDto, EntryMediumDto } from '../../models';
import { BLOCK_HEIGHT, EntryKind } from './magazine-block';
import { sharedMedia } from './magazine-slot-fit';

/** Measured at 390px viewport width, like BLOCK_HEIGHT; a quote share's parts, in the same units. */
const QUOTING = {
  chrome: 150,
  ownLine: 24,
  ownCharsPerLine: 44,
  ownLinesMax: 6,
  quoteChrome: 56,
  quoteLine: 24,
  quoteCharsPerLine: 40,
  quoteLinesMax: 8,
  ownMediaWidth: 342,
  quoteMediaWidth: 318,
  mediaMaxHeight: 480,
  gap: 8,
} as const;

const GRID_RATIO = 16 / 9;

export function blockHeight(kind: EntryKind, entry: EntryDto): number {
  return kind === 'quoting' ? quotingHeight(entry) : BLOCK_HEIGHT[kind];
}

/** Chrome, the post's own text and media, then the quoted box: its header, text and media (#1612). */
export function quotingHeight(entry: EntryDto): number {
  const quote = entry.quote;
  const own =
    QUOTING.ownLine * lineCount(entry.title, QUOTING.ownCharsPerLine, QUOTING.ownLinesMax) +
    withGap(mediaHeight(sharedMedia(entry), QUOTING.ownMediaWidth));
  if (!quote) return QUOTING.chrome + own;
  const quoted =
    QUOTING.quoteChrome +
    QUOTING.quoteLine * lineCount(quote.text, QUOTING.quoteCharsPerLine, QUOTING.quoteLinesMax) +
    withGap(mediaHeight(quote.media, QUOTING.quoteMediaWidth));
  return QUOTING.chrome + own + QUOTING.gap + quoted;
}

/** Lines the text wraps to at the measure, each line break starting a new one, at most `max`. */
function lineCount(text: string, charsPerLine: number, max: number): number {
  if (text === '') return 0;
  const lines = text
    .split('\n')
    .reduce((sum, line) => sum + Math.max(1, Math.ceil(line.length / charsPerLine)), 0);
  return Math.min(lines, max);
}

/** One item at its own shape under the height cap; a grid of 2–4 as one 16:9 block. */
function mediaHeight(media: EntryMediumDto[], width: number): number {
  if (media.length === 0) return 0;
  if (media.length > 1) return width / GRID_RATIO;
  const [only] = media;
  const ratio = only.width && only.height ? only.width / only.height : GRID_RATIO;
  return Math.min(width / ratio, QUOTING.mediaMaxHeight);
}

function withGap(height: number): number {
  return height === 0 ? 0 : height + QUOTING.gap;
}
```
