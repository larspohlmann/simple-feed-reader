# Shared list (#2007) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sharing an entry to a social network records it; a "Shared" sidebar list below Kept shows those entries
(only when there are any), they feed For you, and a Settings switch turns the recording off.

**Architecture:** A nullable `sharedAt` on `EntryState`, set through the existing `PATCH /api/entries/{id}/state`
(`isShared`), gated server-side by a new `remember_shares` preference. A new `EntryView::Shared` ordered by
`sharedAt`, a `sharedCount`, a SHARED history section for the recommender, retention and unsubscribe protection,
backup fields. The frontend records shares through an optional `SHARE_RECORDER` the reader view provides.

**Tech Stack:** Symfony 7.4 / PHP 8.4 / Doctrine (SQLite + MySQL), Angular 20 signals, Jest, PHPUnit 12.

**Spec:** `docs/superpowers/specs/2026-11-03-2007-shared-list-design.md`

  the checkout another session uses: confirm with the user which checkout to work in before the first commit.
