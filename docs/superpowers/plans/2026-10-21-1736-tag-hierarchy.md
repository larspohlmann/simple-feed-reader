# Tag hierarchy (one level of parent tags) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A tag may have a parent tag, one level deep; selecting a parent lists, counts, marks read and refreshes the feeds of the parent and of all its children.

**Architecture:** `Tag` gains a nullable self-reference. One predicate class, `TagScopeDql`, states "a subscription is in a tag's scope when it carries the tag or a child of it" as an EXISTS semi-join, and the four tag-scoped query sites apply it: entry list, mark-read, due feeds, and unread counts (which roll roots up with `COUNT(DISTINCT e.id)`). The wire keeps `tagId`; the tag JSON gains `parentId`. The frontend builds a two-level `TagNode` tree; the sidebar renders children as indented sibling drop lists; drag reorders within one sibling set and only an accepting target highlights; the tag form chooses the parent.

**Tech Stack:** Symfony 7.4 / Doctrine ORM (PHP 8.4), Angular 20 (signals, standalone), Jest, PHPUnit 12.

**Spec:** `docs/superpowers/specs/2026-10-21-1736-tag-hierarchy-design.md` (GitHub issue #1736). Executors read it first.

## Global Constraints

- **Lands after #1735 and #1742.** Both are merged into `feature/1736-tag-hierarchy` (merge commit 23fe99e4d); Task 0 only verifies that.
- One level: a child cannot have children; a tag with children cannot become a child; a tag cannot be its own parent.
- A parent is a normal tag that may carry feeds of its own. Names stay unique per user (`uniq_tag_user_name` unchanged).
- Deleting a parent moves its children to root with positions after the last root; its own feeds become untagged.
- The parent is set in the tag form only. Drag reorders within one sibling set. A drop target accepts a drag only when that drop is allowed, and only an accepting target highlights.
- Wire: `GET /api/entries?tag=`, `POST /api/refresh?tag=`, mark-read `{"scope":"tag"}` take a parent or a child id alike; `TagJson` gains `parentId` (int or null); create/update take `parentId`; `PATCH /api/tags/reorder` lists exactly one sibling set.
- Problem for a bad parent: `422`, type `invalid_tag_parent`, title `Invalid parent tag`, `detail` = the message, `errors: {"parentId": [message]}`. Messages, verbatim: `The parent tag does not exist.`, `A parent tag cannot itself have a parent.`, `A tag with child tags cannot have a parent.`, `A tag cannot be its own parent.`
- Reorder guard message, verbatim: `tagIds must list exactly one tag and all of its siblings.`
- Backup: `BackupSchema::VERSION` stays `3`; the tag line gains `parent` (name or null); roots are written before children; the tally refuses `The backup names parent tag "%s" before declaring it.`
- House rules (`CLAUDE.md`): `final readonly`, no abbreviations, no comment unless a reader would get the code wrong without it, `Response::HTTP_*` constants, PHPMD-clean touched files, `declare(strict_types=1)`, `type(#1736): …` commit messages, no attribution lines, keep a native iOS client viable (plain JSON).
- Frontend: Prettier 100 columns; no hex colours or raw `px` in component SCSS; component styles in the sibling `.scss`; run Jest only inside the Docker frontend container (`docker compose exec -T frontend npx jest <path>`), one run at a time.
- Backend commands run from `backend/`: `php bin/phpunit <path>`, `composer check`, `composer md`. Frontend from `frontend/`.

- [ ] **Step 5: Resolve the parent in the editor**

In `TagEditor`, import the exception and change `create()` and `update()`; add `parentForNew()`, `parentFor()` and the shared `resolveParent()`:

```php
    public function create(User $user, TagDetailsModel $details): Tag
    {
        if ($this->tags->existsForUserAndName($user->requireId(), $details->name)) {
            throw new TagNameTakenException();
        }

        $tag = $this->tagFactory->create($user, $details, $this->tags->nextPositionForUser($user->requireId()));
        $tag->setParent($this->parentForNew($user, $details->parentId));
        $this->entityManager->persist($tag);
        $this->entityManager->flush();

        return $tag;
    }

    public function update(Tag $tag, TagDetailsModel $details): void
    {
        if ($this->tags->existsForUserAndName($tag->getUser()->requireId(), $details->name, $tag->requireId())) {
            throw new TagNameTakenException();
        }

        $tag->setParent($this->parentFor($tag, $details->parentId));
        $tag->setName($details->name);
        $tag->setColor($details->color);
        $tag->setIcon($details->icon);
        $this->entityManager->flush();
    }

    private function parentForNew(User $user, ?int $parentId): ?Tag
    {
        return $parentId === null ? null : $this->resolveParent($user, $parentId);
    }

    private function parentFor(Tag $tag, ?int $parentId): ?Tag
    {
        if ($parentId === null) {
            return null;
        }
        if ($tag->getId() === $parentId) {
            throw InvalidTagParentException::itself();
        }
        if ($this->tags->hasChildren($tag)) {
            throw InvalidTagParentException::tagHasChildren();
        }

        return $this->resolveParent($tag->getUser(), $parentId);
    }

    private function resolveParent(User $user, int $parentId): Tag
    {
        $parent = $this->tags->findOneForUser($user->requireId(), $parentId) ?? throw InvalidTagParentException::unknown();
        if ($parent->getParent() !== null) {
            throw InvalidTagParentException::parentIsAChild();
        }

        return $parent;
    }
```

```php
    private function perChildTag(int $userId): array
    {
        $qb = $this->taggedUnreadEntries($userId)->andWhere('t.parent IS NOT NULL');
```

```php
<?php

declare(strict_types=1);

namespace App\Service\Opml\Pass;

use App\Entity\Tag;
use App\Service\Social\Model\ExportedSubscriptionModel;

/** One export's tags and their feeds, arranged for nesting: a parent appears even when only its child has feeds. */
final class OpmlTagTree
{
    /** @var array<int, Tag> by tag id */
    private array $tags = [];

    /** @var array<int, list<ExportedSubscriptionModel>> by tag id */
    private array $feedsByTag = [];

    /** @var list<ExportedSubscriptionModel> */
    private array $untagged = [];

    /** @param list<ExportedSubscriptionModel> $subscriptions */
    public function __construct(array $subscriptions)
    {
        foreach ($subscriptions as $exported) {
            $tags = $exported->subscription->getTags();
            if ($tags->isEmpty()) {
                $this->untagged[] = $exported;
                continue;
            }
            foreach ($tags as $tag) {
                $this->remember($tag);
                $this->feedsByTag[$tag->requireId()][] = $exported;
            }
        }
    }

    /** @return list<Tag> */
    public function roots(): array
    {
        return $this->ordered(static fn (Tag $tag): bool => $tag->getParent() === null);
    }

    /** @return list<Tag> */
    public function childrenOf(Tag $parent): array
    {
        return $this->ordered(static fn (Tag $tag): bool => $tag->getParent()?->getId() === $parent->getId());
    }

    /** @return list<ExportedSubscriptionModel> */
    public function feedsOf(Tag $tag): array
    {
        return $this->feedsByTag[$tag->requireId()] ?? [];
    }

    /** @return list<ExportedSubscriptionModel> */
    public function untagged(): array
    {
        return $this->untagged;
    }

    private function remember(Tag $tag): void
    {
        $this->tags[$tag->requireId()] = $tag;
        $parent = $tag->getParent();
        if ($parent !== null) {
            $this->tags[$parent->requireId()] = $parent;
        }
    }

    /**
     * @param \Closure(Tag): bool $keep
     *
     * @return list<Tag>
     */
    private function ordered(\Closure $keep): array
    {
        $tags = array_values(array_filter($this->tags, $keep));
        usort($tags, static fn (Tag $left, Tag $right): int => [$left->getPosition(), $left->getName()]
            <=> [$right->getPosition(), $right->getName()]);

        return $tags;
    }
}
```

```php
     * @return list<Tag> the tags this call brought into being
     */
    private function attachTag(
        BulkSubscribeBatch $batch,
        Subscription $subscription,
        BulkSubscribeItemModel $item,
    ): array {
        if (null === $item->tagName) {
            return [];
        }

        $name = $this->clippedTagName($item->tagName);
        $existing = $this->existingTag($batch, $name);
        $tag = $existing ?? $this->persistNewTag($batch, $name, $item->tagStyle);
        $batch->rememberTag($name, $tag);
        $this->joinTag($batch->positions, $subscription, $tag);
        $created = null === $existing ? [$tag] : [];

        return [...$created, ...$this->nestUnder($batch, $tag, $item->parentTagName)];

    /**
     * The one-level rule decides silently, so an import never fails on a tag the user already arranged.
     *
     * @return list<Tag> the parent, when this call brought it into being
     */
    private function nestUnder(BulkSubscribeBatch $batch, Tag $tag, ?string $parentName): array
    {
        if (null === $parentName || null !== $tag->getParent() || $this->isParent($batch, $tag)) {
            return [];
        }
        $name = $this->clippedTagName($parentName);
        $existing = $this->existingTag($batch, $name);
        if (null !== $existing && ($existing === $tag || null !== $existing->getParent())) {
            return [];

        $parent = $existing ?? $this->persistNewTag($batch, $name, null);
        $batch->rememberTag($name, $parent);
        $tag->setParent($parent);
        $batch->rememberParent($parent);
```

```ts
export interface TagNode {
  tag: TagDto;
  subscriptions: SubscriptionDto[];
  /** A root's children in position order; always empty on a child (#1736). */
  children: TagNode[];
  unreadCount: number;
  entryCount: number;
}

/**
 * Build the sidebar tag tree, one level deep. Tag NODES and their order come
 * from `orderedTags` (already in `tag.position` order) so every tag shows,
 * including empty ones; each node's feeds come from `subs` carrying the tag.
 * A root's unread count is the API's roll-up; its entry count spans its own
 * feeds and its children's, a feed carrying both counted once. Falls back to
 * the tags embedded on subscriptions, name-ordered, before the tag list has
 * loaded, so tagged feeds never briefly vanish.
 */
export function buildTagTree(
  subscriptions: SubscriptionDto[],
  orderedTags: TagDto[] = [],
  tagUnread: ReadonlyMap<number, number> = new Map(),
): TagNode[] {
  const tags = orderedTags.length > 0 ? orderedTags : embeddedTagsByName(subscriptions);
  const byTagId = bucketByTag(subscriptions);
  const knownIds = new Set(tags.map((tag) => tag.id));
  const isRoot = (tag: TagDto): boolean => tag.parentId === null || !knownIds.has(tag.parentId);

  const leaf = (tag: TagDto): TagNode => {
    const feeds = feedsOf(byTagId, tag.id);
    return {
      tag,
      subscriptions: feeds,
      children: [],
      unreadCount: tagUnread.get(tag.id) ?? 0,
      entryCount: totalEntryCount(feeds),
    };
  };

  return tags.filter(isRoot).map((root) => {
    const node = { ...leaf(root), children: tags.filter((tag) => tag.parentId === root.id).map(leaf) };
    return { ...node, entryCount: totalEntryCount(distinctFeedsOf(node)) };
  });
}

/** Every node, each root followed by its children: the order the sidebar shows. */
export function flattenTagTree(nodes: TagNode[]): TagNode[] {
  return nodes.flatMap((node) => [node, ...node.children]);
}

/** Each root followed by its children, whatever order the caller holds them in. */
export function tagsInTreeOrder(tags: TagDto[]): TagDto[] {
  const knownIds = new Set(tags.map((tag) => tag.id));
  return tags
    .filter((tag) => tag.parentId === null || !knownIds.has(tag.parentId))
    .flatMap((root) => [root, ...tags.filter((tag) => tag.parentId === root.id)]);
}

type TaggedFeed = { sub: SubscriptionDto; pos: number };

/** One pass over subscriptions buckets each feed under every tag it carries, with its per-tag position. */
function bucketByTag(subscriptions: SubscriptionDto[]): Map<number, TaggedFeed[]> {
  const byTagId = new Map<number, TaggedFeed[]>();
  for (const sub of subscriptions) {
    for (const tag of sub.tags) {
      let bucket = byTagId.get(tag.id);
      if (!bucket) {
        bucket = [];
        byTagId.set(tag.id, bucket);
      }
      bucket.push({ sub, pos: tag.position });
    }
  }
  return byTagId;
}

function feedsOf(byTagId: Map<number, TaggedFeed[]>, tagId: number): SubscriptionDto[] {
  return (byTagId.get(tagId) ?? [])
    .sort((left, right) => left.pos - right.pos || left.sub.title.localeCompare(right.sub.title))
    .map((tagged) => tagged.sub);
}

function distinctFeedsOf(node: TagNode): SubscriptionDto[] {
  const byId = new Map<number, SubscriptionDto>();
  for (const feed of [...node.subscriptions, ...node.children.flatMap((child) => child.subscriptions)]) {
    byId.set(feed.id, feed);
  }
  return [...byId.values()];
}
```

```ts
import { Injectable, computed, signal } from '@angular/core';
import { TagMove, gapIndexAt, isNoOpGap } from './tag-drop-gap';

/** The pointer range, relative to the tree's top, inside which a gap may show. */
export interface TagDragBounds {
  readonly top: number;
  readonly bottom: number;
}

interface TagDrag {
  readonly from: number;
  readonly middles: readonly number[];
  readonly bounds: TagDragBounds | null;
}

function isOutside(offsetY: number, bounds: TagDragBounds | null): boolean {
  return bounds !== null && (offsetY < bounds.top || offsetY > bounds.bottom);
}

@Injectable()
export class TagDragGap {
  private readonly drag = signal<TagDrag | null>(null);
  private readonly offsetY = signal<number | null>(null);

  readonly gap = computed(() => {
    const drag = this.drag();
    const offsetY = this.offsetY();
    if (drag === null || offsetY === null || isOutside(offsetY, drag.bounds)) return null;
    const gap = gapIndexAt(offsetY, drag.middles);
    return isNoOpGap(drag.from, gap) ? null : gap;
  });

  /** `middles` are the tag panels' midpoints, measured once, relative to the tree's top. */
  start(from: number, middles: readonly number[], bounds: TagDragBounds | null = null): void {
    this.drag.set({ from, middles, bounds });
    this.offsetY.set(null);
  }
```

```ts
  /** The dragged tag's siblings as group indexes, and the group a gap after the last sibling draws before. */
  private readonly dragSiblings = signal<{ groupIndexes: number[]; afterLast: number } | null>(null);
  private readonly draggedTag = signal<TagDto | null>(null);

  /** The sibling gap, mapped onto the group it draws before. */
  protected readonly gapGroupIndex = computed<number | null>(() => {
    const gap = this.tagGap.gap();
    const siblings = this.dragSiblings();
    if (gap === null || siblings === null) return null;
    return gap < siblings.groupIndexes.length ? siblings.groupIndexes[gap] : siblings.afterLast;
  });

  protected canMoveTag(group: OrganiseGroup, offset: number): boolean {
    if (group.tag === null || this.store.filterActive()) return false;
    const ids = this.siblingIds(group.tag);
    const to = ids.indexOf(group.tag.id) + offset;
    return to >= 0 && to < ids.length;
  }

  protected moveTag(group: OrganiseGroup, offset: number): void {
    if (group.tag === null) return;
    const ids = this.siblingIds(group.tag);
    const from = ids.indexOf(group.tag.id);
    const to = from + offset;
    if (from < 0 || to < 0 || to >= ids.length) return;
    [ids[from], ids[to]] = [ids[to], ids[from]];
    this.persistTagOrder(ids);
  }

  protected startTagDrag(group: OrganiseGroup): void {
    const tag = group.tag;
    if (tag === null) return;
    const groups = this.store.groups();
    const panels = this.panels();
    const treeTop = this.treeTop();
    const groupIndexes = groups.flatMap((shown, index) =>
      shown.tag !== null && shown.tag.parentId === tag.parentId ? [index] : [],
    );
    const afterLast = groupAfter(groups, groupIndexes[groupIndexes.length - 1]);
    this.draggedTag.set(tag);
    this.dragSiblings.set({ groupIndexes, afterLast });
    this.tagGap.start(
      groupIndexes.indexOf(groups.indexOf(group)),
      groupIndexes.map((index) => verticalMiddle(panels[index].nativeElement) - treeTop),
      tag.parentId === null ? null : this.spanOf(groupIndexes[0], afterLast - 1),
    );
  }

  /** First panel's top to last panel's foot, relative to the tree. The foot is top + height, as the panels report it. */
  private spanOf(first: number, last: number): TagDragBounds {
    const treeTop = this.treeTop();
    const firstRect = this.panels()[first].nativeElement.getBoundingClientRect();
    const lastRect = this.panels()[last].nativeElement.getBoundingClientRect();
    return { top: firstRect.top - treeTop, bottom: lastRect.top + lastRect.height - treeTop };
  }

  protected endTagDrag(): void {
    const move = this.tagGap.end();
    const tag = this.draggedTag();
    this.draggedTag.set(null);
    this.dragSiblings.set(null);
    if (move !== null && tag !== null) this.persistTagOrder(moveToGap(this.siblingIds(tag), move));
  }

  private siblingIds(tag: TagDto): number[] {
    return this.tags
      .tags()
      .filter((candidate) => candidate.parentId === tag.parentId)
      .map((candidate) => candidate.id);
  }
```
