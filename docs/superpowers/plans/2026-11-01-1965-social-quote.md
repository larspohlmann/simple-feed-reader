# Quote Bluesky and Mastodon posts (#1965) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Quote the article's post or any reply from the Repost / Quote menu, through the #1964 composer, with Quote disabled (with a reason) where the network forbids it.

**Architecture:** The #1964 reply pipeline generalises to "write a post that responds to a target": a reply and a quote differ only in how the target is attached (Bluesky `reply` refs vs an `app.bsky.embed.record` embed; Mastodon `in_reply_to_id` vs `quoted_status_id`) and in which permission gates them. Task 1 renames the reply-only names so they stop lying; later tasks add `quote` beside `reply` on the same writer strategy, a `canQuote` flag next to `canReply`, a `kind` on the composer, and a Quote item in the existing repost menu.

**Tech Stack:** Symfony 7.4 / PHP 8.4, Angular 20 signals, CDK overlay/dialog, Transloco.

**Spec:** umbrella issue #1962 (agreed design), slice issue #1965.

## Global Constraints

- Same network only; acting account resolves as for replies (`ResponseTargetFinder`, explicit `accountId` from the composer).
- Restricted actions are disabled with a tooltip, never hidden.
- Bluesky gate: `viewer.embeddingDisabled` (lexicon `app.bsky.feed.defs#viewerState`). Quote record: `embed: {"$type": "app.bsky.embed.record", "record": {"uri", "cid"}}` (lexicon `app.bsky.embed.record`, `record` is a `com.atproto.repo.strongRef`).
- Mastodon gate: the status's `quote_approval.current_user` is `automatic` or `manual` (docs: entities/QuoteApproval). The field exists only on 4.5+, so its absence means "instance too old" — no version probe. `denied` and `unknown` both disable (docs advise treating `unknown` as denied).
- Mastodon send: `POST /api/v1/statuses` with `quoted_status_id` (4.5.0); a refusal is a 422, already mapped to `SocialPostRefusedException` by `MastodonAccountApi::writeAs`.
- Writes draw on `social_writes`; the composer GET on `social_viewer`.
- After sending a quote: toast with an **Open** action to the new post's web URL; the quotes count steps up when the quoted post is the entry's own post.
- Quote composer prefills no mentions; visibility default is the same stricter-of rule as replies.
- Clean Code rules in CLAUDE.md; PHPMD-clean touched files; en/de i18n parity; Prettier 100 cols.

### Task 2: `canQuote` on every post the reader shows

**Interfaces:** `ResponseContextModel` gains `public bool $canQuote = true`; `CommentViewerModel` gains `bool $canQuote = true`; new `Support/MastodonQuoting::allows(JsonNodeModel $status): bool`.

- [ ] Test `MastodonQuotingTest`: `automatic` and `manual` allow; `denied`, `unknown`, missing `quote_approval`, missing `current_user` refuse (data provider).
- [ ] Implement:

```php
/** Mastodon 4.5+ says per post whether the asking user may quote it; an older instance says nothing. */
final class MastodonQuoting
{
    private const array ALLOWED = ['automatic', 'manual'];

    public static function allows(JsonNodeModel $status): bool
    {
        return \in_array($status->node('quote_approval')->string('current_user'), self::ALLOWED, true);
    }
}
```

- [ ] Resolvers: Bluesky `canQuote: !$post->node('viewer')->isTrue('embeddingDisabled')`; Mastodon `canQuote: MastodonQuoting::allows($status)` in `replyContextOf` (rename it `responseContextOf`).
