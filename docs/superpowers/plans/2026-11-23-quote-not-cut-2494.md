# Shared quote starts whole (#2494) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sharing a selected passage starts the composer from the whole quote, not one cut to the network's limit, and the share menu sends selections up to 2500 characters.

**Architecture:** `ComposerStartingText` stops clipping: `quoting()` and `sharing()` lose their room parameter and wrap the quote whole. The composer already counts the text per network, marks a counter `over` and blocks Send (`composer-dialog.component.ts` `counters`/`pendingFit`), so the reader shortens it there. The transport cap `QUOTE_MAX` (GET query string) rises from 1000 to 2500 on both sides.

**Tech Stack:** Symfony 8.1 / PHPUnit 12, Angular 20 / Jest.

**Spec:** GitHub issue #2494.

## Global Constraints

- `QUOTE_MAX = 2500` in `backend/src/Dto/Social/LinkTargetQuery.php` and `frontend/src/app/reader/article/share/share-content.ts`; the two stay equal.
- A selection past 2500 characters is still clipped at a word by `clippedAtWord()` (frontend); the backend still refuses more than `QUOTE_MAX` with 422.
- Typographic quotes `“…”` around the quote stay.
- This overrides the #1970 ruling "trimmed to the network's limit".

## Review Focus

- A quote over the network limit (e.g. 400 characters on Bluesky): the composer opens with all of it, the counter is `over`, Send is blocked. Pinned by the controller test in Task 1 (`text` is the whole quote while `maxCharacters` is smaller).
- A quote of a post with a selection (`LinkSharing` → `ComposerContexts::buildQuoteContext`) starts whole too. Covered by the `quoting()` unit test, since both paths call it.
- A Lemmy link post with a quote (`buildLinkText` Lemmy branch) starts whole. Same `quoting()` call.
- Exactly 2500 characters passes the backend; 2501 is refused. Pinned by the existing `testTheLinkComposerRefusesAQuoteLongerThanTheFrontendSends` (reads the constant) plus the frontend spec in Task 2.
- A long non-ASCII selection grows about 6× when URL-encoded and can hit a server's request-line limit (around 8 KB). This is accepted with the 2500 cap; it is not tested here.
