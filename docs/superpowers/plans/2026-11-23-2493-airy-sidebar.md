# Airy Sidebar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A second sidebar design, `airy`, stored as an account preference `sidebarStyle` and picked in Settings under the magazine style.

**Architecture:** Backend: a `SidebarStyle` enum column on `user_reading_settings`, carried by the preferences `PATCH`, `/api/me` and the backup line, exactly as `magazineStyle` is. Frontend: the three "account is the record, `localStorage` is the paint cache" services (magazine style, handedness, the new sidebar style) share one base; the shell puts an `airy` class on `aside.sidebar`, and the sidebar components draw variant A under `:host-context(.airy)`.

**Tech Stack:** Symfony 8.1 / Doctrine (PHP 8.5), Angular 20 standalone + signals, SCSS tokens, Jest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-23-airy-sidebar-design.md` (issue #2493). The look's reference implementation is the mock stylesheet `.superpowers/brainstorm/airy-sidebar/mock/vh1.css` (gitignored, on this machine); port its rules, not its `!important`s.

## Global Constraints

- Values: `boxed` (default) | `airy`. JSON key `sidebarStyle`; column `sidebar_style VARCHAR(10) DEFAULT 'boxed' NOT NULL`; `localStorage` key `sfr.sidebarStyle`.
- `boxed` stays pixel-identical to today. Nothing in the sidebar footer's view controls changes.
- An unknown or missing backup value restores as `boxed` (restore over reject), like `magazineStyle`.
- Frontend `.scss`: tokens only, no hex, no `px` literals except `1px` hairlines and the `3px` current bar already used in the mock; no `!important`.
- Commit messages `type(#2493): …`, no attribution lines.
- Copy (en / de / fr / es): `settings.sidebarStyle` "Sidebar style" / "Seitenleisten-Stil" / "Style de la barre latérale" / "Estilo de la barra lateral"; `settings.sidebarStyleHint` "How the sidebar is drawn." / "Wie die Seitenleiste dargestellt wird." / "Comment la barre latérale est affichée." / "Cómo se dibuja la barra lateral."; `settings.sidebarStyleSaveFailed` "The sidebar style could not be saved to your account." / "Der Seitenleisten-Stil konnte nicht in deinem Konto gespeichert werden." / "Le style de la barre latérale n'a pas pu être enregistré dans votre compte." / "No se pudo guardar el estilo de la barra lateral en tu cuenta."; `settings.sidebarStyleOption.boxed|airy` reuse each language's magazine labels (Boxed/Airy, Mit Rahmen/Luftig, Encadré/Aéré, En recuadros/Espaciado).

## Review Focus

- Logout then sign-in as another account: the sidebar must not keep the previous account's `airy` (reset clears the cache) — Task 3 test.
- A `PATCH` naming only `sidebarStyle` is a valid change (`isEmpty()` must count it) — Task 1 test.
- Coarse pointer (phone drawer): section heads keep `--tap-target` height under `airy` — Task 4 e2e assertion.
- Switching style while the drawer is open repaints without reload (class is a signal binding) — Task 4 e2e.
- `boxed` unchanged: the existing sidebar e2e/Jest suites stay green untouched — Task 4 verification.
