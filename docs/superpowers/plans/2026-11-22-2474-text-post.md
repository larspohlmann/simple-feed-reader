# Text Post from the Sidebar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A '+' left of the bell in the Bluesky and Mastodon sidebar card heads opens the composer for a new text post with no link, crosspostable between Bluesky and Mastodon.

**Architecture:** Built on #2476's general publish path. Backend: `ComposerKind::Post`, a `TextPosts` service whose publication carries nothing attached, and a `SocialTextPostController` with `GET /api/social/post-composer` + `POST /api/social/posts`. Frontend: `ComposeRequest` gains `PostRequest`; a root `TextPostComposer` opens it through the generic `Composer` and keeps one session draft; the sidebar gets a `SidebarComposeButtonComponent` beside the bell.

**Tech Stack:** Symfony 8.1 / PHP 8.5, Angular 20 signals, Transloco (en/de/fr/es), Jest in Docker, Playwright.

**Spec:** GitHub issue #2474 body (design + architecture, grilled 2026-11-22).

## Global Constraints

- '+' sits **left of the bell**, same size and muted tone (`--icon-dense`, `--text-muted`), plain `add` glyph; bell badge stays outermost.
- '+' shows exactly when the bell shows (`section.networkAccounts.length > 0`); disabled with a tooltip when no account of that network has status `connected`; never on Lemmy.
- Phone: tapping '+' closes the drawer, the composer opens full height (`fillOnMobile`, already on the dialog).
- Crosspost pills: Bluesky + Mastodon (connected ones), only the clicked network on at the start; no Lemmy pill.
- Over limit: counter red, Send disabled (existing lane logic); no threading.
- One session draft in memory (not storage), shared by both '+'; reopening restores the text, pills reset; any send that reached a network clears it; logout clears it (`onIdentityChange`).
- After sending: the existing post-sent dialog only; no list insert, no refresh.
- Routes: `GET /api/social/post-composer?network=&accountId=`, `POST /api/social/posts` (JSON body, 201 + `PublishedPostJson`), problem+json errors; iOS checklist (bearer, stateless, no browser inputs).
- Text required and ≤ 10000 characters in the request (same as `PostDraftRequest`).
- No keyboard shortcut. All user copy in en/de/fr/es.

## Review Focus

1. Lemmy reached through the new routes (hand-crafted request) → `social_post_refused` problem, nothing posted. Test in Task 1.
2. Draft after a partly failed crosspost then Cancel → cleared, because one network took it. Test in Task 3.
3. Draft after logout/login on the same tab → empty. Test in Task 3.
4. A connected Bluesky but a Mastodon needing reconnect → Mastodon '+' disabled with tooltip, Bluesky '+' opens with only Bluesky in the pills. Test in Task 4.
5. Whitespace-only text → Send disabled in the SPA and 422 from the API. Tests in Tasks 1 and 2.
