# #1363 Jev: favorites in the System One state — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Jev requests carry the reader's favorites beside the profile and guidance, as the LLM prompt's FAVORITES section does.

**Architecture:** `RecommendationHistoryLoader` gains `favorites(userId, settings)`, which `load()` reuses. `JevStateFactory::create($profile, $guidance, $favorites)` adds `favorites`: a list of `JevArticle::of()` objects, newest first. It keeps whole favorites only while the state stays within `STATE_TOKEN_BUDGET`, which rises from 4,000 to 10,000. Guidance is fitted first, then profile, then favorites. The key is omitted when no favorite fits or none exist. `JevRecommendationEngine::waveOf()` loads the favorites per wave. `SystemOneRequestFactory::QUESTION` names them.

**Tech Stack:** Symfony 7.4 / PHP 8.4, PHPUnit.

## Global Constraints

- `composer check`, `composer md` clean; both test legs green.
- Favorites cap is the existing `historyCaps->favorites`.
