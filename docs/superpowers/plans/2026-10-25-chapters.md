# Chapters Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show a chapter list in the article view for YouTube videos (from the description) and podcast episodes (from Podlove `psc:chapters` and `podcast:chapters` JSON); a tap seeks and plays, and the current chapter is highlighted while it plays.

**Architecture:** A new `Service/Chapter` module parses chapters. YouTube chapters are read from the stored body each time the entry detail is served, and the timestamp block is removed from the body sent. Podcast chapters live on the entry in an `EntryChapters` embeddable: inline chapters are stored at ingest, a JSON chapters URL is stored at ingest and fetched the first time the article is opened. `GET /api/entries/{id}` gains `chapters`. In the SPA, a DOM decorator draws the list beside the other article decorators and drives a `ChapterPlayer`: the YouTube iframe through its `postMessage` API, or the app-wide `AudioPlayerService`.

**Tech Stack:** Symfony 7.4 / PHP 8.4 (`\Dom\HTMLDocument`, Doctrine embeddables, PHPUnit 12), Angular 20 (signals, standalone), Jest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-25-chapters-design.md`. This plan deviates from it in three places, each decided while reading the code. Task 1 updates the spec to match:

1. **Podcast chapters live on the entry, not in the attachment JSON.** Chapters belong to the feed item, not to an enclosure. `App\Entity` may not import a Service model (`PersistenceKnowsNoServiceRule`). And refilling one key inside the attachment list would mean rebuilding every attachment. So there is a new embeddable `EntryChapters` (`chapters` JSON + `chapters_url`) and one migration.
2. **No new frame-allowlist pattern.** The allowlist validates the untrusted link in the body. The `?enablejsapi=1&origin=…` suffix is a constant the SPA appends after that validation (`withPlayerApi`), so the generated allowlist and `YouTubeEmbedProvider` stay unchanged.
3. **The chapter list is a DOM decorator, not an Angular component.** The article body is `innerHTML`, decorated in place by functions such as `addCinemaToggles` and `hydrateSlideshows`. "Under the player" is a position inside that HTML, which a component can't occupy. `ChapterPlayer` keeps the spec's role, but has `watch`/`release` instead of a signal so that plain DOM code can use it.

```php
<?php

declare(strict_types=1);

namespace App\Entity;

use App\Entity\Exception\IncompleteStoredMediaException;

final readonly class EntryChapter implements \JsonSerializable
{
    public function __construct(public int $startSeconds, public string $title)
    {
    }

    /**
     * @param array<string, mixed> $stored
     *
     * @phpstan-assert-if-true array{startSeconds: int, title: string, ...<mixed>} $stored
     */
    public static function isComplete(array $stored): bool
    {
        return \is_int($stored['startSeconds'] ?? null) && \is_string($stored['title'] ?? null);
    }

    /** @param array<string, mixed> $stored */
    public static function fromStored(array $stored): self
    {
        if (!self::isComplete($stored)) {
            throw new IncompleteStoredMediaException('A stored chapter needs a start and a title.');
        }

        return new self($stored['startSeconds'], $stored['title']);
    }

    /** @return array{startSeconds: int, title: string} */
    public function jsonSerialize(): array
    {
        return ['startSeconds' => $this->startSeconds, 'title' => $this->title];
    }
}
```

`backend/src/Entity/EntryChapters.php`:

```php
<?php

declare(strict_types=1);

namespace App\Entity;

use Doctrine\DBAL\Types\Types;
use Doctrine\ORM\Mapping as ORM;

/** An entry's chapters, and the chapters file still to fetch for them when the feed only linked one. */
#[ORM\Embeddable]
final class EntryChapters
{
    public const int URL_MAX_LENGTH = 2048;

    /** @var list<array<string, mixed>>|null */
    #[ORM\Column(name: 'chapters', type: Types::JSON, nullable: true)]
    private ?array $chapters = null;

    #[ORM\Column(name: 'chapters_url', length: self::URL_MAX_LENGTH, nullable: true)]
    private ?string $url = null;

    /** @param list<EntryChapter> $chapters */
    public function declare(array $chapters, ?string $url): void
    {
        $this->chapters = self::stored($chapters);
        $this->url = $chapters === [] && $url !== null && \strlen($url) <= self::URL_MAX_LENGTH ? $url : null;
    }

    /** @param list<EntryChapter> $chapters */
    public function fill(array $chapters): void
    {
        $this->chapters = self::stored($chapters);
        $this->url = null;
    }

    /** @return list<EntryChapter> */
    public function getChapters(): array
    {
        return StoredList::read($this->chapters, EntryChapter::isComplete(...), EntryChapter::fromStored(...));
    }

    public function getUrl(): ?string
    {
        return $this->url;
    }

    /**
     * @param list<EntryChapter> $chapters
     *
     * @return list<array{startSeconds: int, title: string}>|null
     */
    private static function stored(array $chapters): ?array
    {
        return StoredList::orNull(array_map(
            static fn (EntryChapter $chapter): array => $chapter->jsonSerialize(),
            $chapters,
        ));
    }
}
```

```php
<?php

declare(strict_types=1);

namespace App\Service\Chapter\Support;

/** A chapter start as written in a description, a Podlove `start` or a clock: `S`, `M:SS`, `H:MM:SS`, any fraction floored. */
final class ChapterClock
{
    private const string PATTERN = '/^\d+(?::\d+){0,2}(?:\.\d+)?$/';

    public static function seconds(string $clock): ?int
    {
        $trimmed = trim($clock);
        if (preg_match(self::PATTERN, $trimmed) !== 1) {
            return null;
        }

        $parts = explode(':', explode('.', $trimmed, 2)[0]);
        $total = 0;
        foreach ($parts as $index => $part) {
            if ($index > 0 && (int) $part > 59) {
                return null;
            }
            $total = $total * 60 + (int) $part;
        }

        return $total;
    }

    private function __construct()
    {
    }
}
```

```php
<?php

declare(strict_types=1);

namespace App\Service\Chapter\Support;

use App\Entity\EntryChapter;

final class ChapterSequence
{
    /**
     * @param list<EntryChapter> $chapters
     *
     * @return list<EntryChapter>
     */
    public static function ordered(array $chapters): array
    {
        usort($chapters, static fn (EntryChapter $left, EntryChapter $right): int => $left->startSeconds <=> $right->startSeconds);

        return \count($chapters) >= 2 && self::ascends($chapters) ? $chapters : [];
    }

    /** @param list<EntryChapter> $chapters */
    public static function ascends(array $chapters): bool
    {
        for ($index = 1, $count = \count($chapters); $index < $count; $index++) {
            if ($chapters[$index]->startSeconds <= $chapters[$index - 1]->startSeconds) {
                return false;
            }
        }

        return true;
    }

    private function __construct()
    {
    }
}
```

```php
    public static function of(Document $document): array
    {
        $lines = [];
        foreach ($document->querySelectorAll('p, li') as $block) {
            array_push($lines, ...self::inBlock($block));
        }

        return $lines;

    /** @return list<DescriptionLine> */

    {
        $lines = [];

            if (self::isBreak($child)) {
                $lines[] = new DescriptionLine($block, $nodes, $child);
                $nodes = [];
                continue;
            }
            $nodes[] = $child;
        }
        $lines[] = new DescriptionLine($block, $nodes, null);

        return $lines;
    }

    /** @phpstan-assert-if-true Element $node */
    private static function isBreak(Node $node): bool
    {
        return $node instanceof Element && $node->localName === 'br';
```

```php
<?php

declare(strict_types=1);

namespace App\Service\Chapter\Support;

use App\Entity\EntryChapter;
use App\Service\Chapter\Model\DescribedChaptersModel;
use App\Service\Chapter\Pass\DescriptionLine;
use App\Service\Html\Support\HtmlDocumentParser;
use Dom\Element;
use Dom\Text;

/** YouTube's chapter rule over a video description: the first `0:00`-led block of three or more ascending stamps. */
final class DescriptionChapters
{
    private const string LINE = '/^\s*[(\[]?((?:\d{1,2}:)?\d{1,2}:\d{2})[)\]]?\s*[-–—:|]?\s*(\S.*?)\s*$/u';
    private const int MINIMUM = 3;

    public static function in(string $html): DescribedChaptersModel
    {
        $document = HtmlDocumentParser::parseFragment($html);
        $run = self::firstRun(DescriptionLines::of($document));
        if ($run === []) {
            return new DescribedChaptersModel([], $html);
        }

        $chapters = array_map(static fn (array $pair): EntryChapter => $pair[1], $run);
        foreach ($run as [$line]) {
            $line->remove();
            self::tidy($line->block);
        }

        return new DescribedChaptersModel($chapters, $document->body->innerHTML ?? $html);
    }

    /**
     * @param list<DescriptionLine> $lines
     *
     * @return list<array{DescriptionLine, EntryChapter}>
     */
    private static function firstRun(array $lines): array
    {
        $run = [];
        foreach ([...$lines, null] as $line) {
            $chapter = $line === null ? null : self::chapterOf($line->text());
            if ($line !== null && $chapter !== null) {
                $run[] = [$line, $chapter];
                continue;
            }
            if (self::isChapterBlock($run)) {
                return $run;
            }
            $run = [];
        }

        return [];
    }

    /** @param list<array{DescriptionLine, EntryChapter}> $run */
    private static function isChapterBlock(array $run): bool
    {
        $chapters = array_map(static fn (array $pair): EntryChapter => $pair[1], $run);

        return \count($chapters) >= self::MINIMUM
            && $chapters[0]->startSeconds === 0
            && ChapterSequence::ascends($chapters);
    }

    private static function chapterOf(string $text): ?EntryChapter
    {
        if (preg_match(self::LINE, $text, $match) !== 1) {
            return null;
        }
        $start = ChapterClock::seconds($match[1]);

        return $start === null ? null : new EntryChapter($start, $match[2]);
    }

    private static function tidy(Element $block): void
    {
        $last = $block->lastChild;
        while ($last instanceof Text && trim($last->data) === '') {
            $last = $last->previousSibling;
        }
        if ($last instanceof Element && $last->localName === 'br') {
            $last->remove();
        }
        if (trim((string) $block->textContent) === '' && $block->firstElementChild === null) {
            $block->remove();
        }
    }

    private function __construct()
    {
    }
}
```

`firstRun` returns as soon as a run ends that qualifies, which also makes a qualifying block the first one.

```php
<?php

declare(strict_types=1);

namespace App\Service\Chapter\Support;

use App\Entity\EntryChapter;

/** A Podcasting 2.0 JSON chapters file (`podcast:chapters`) as an ordered chapter list. */
final class JsonChapters
{
    /**
     * @param array<mixed> $file
     *
     * @return list<EntryChapter>
     */
    public static function from(array $file): array
    {
        $rows = $file['chapters'] ?? null;
        if (!\is_array($rows)) {
            return [];
        }

        $chapters = [];
        foreach ($rows as $row) {
            $chapter = \is_array($row) ? self::chapterOf($row) : null;
            if ($chapter !== null) {
                $chapters[] = $chapter;
            }
        }

        return ChapterSequence::ordered($chapters);
    }

    /** @param array<mixed> $row */
    private static function chapterOf(array $row): ?EntryChapter
    {
        $start = $row['startTime'] ?? null;
        $title = \is_string($row['title'] ?? null) ? trim($row['title']) : '';
        $listed = ($row['toc'] ?? true) !== false;

        return (\is_int($start) || \is_float($start)) && $start >= 0 && $title !== '' && $listed
```

```ts
/** The chapter playing at `seconds`, as an index into ascending `starts`; -1 before the first or with no position. */
export function currentChapterIndex(starts: readonly number[], seconds: number | null): number {
  if (seconds === null) return -1;
  let low = 0;
  let high = starts.length - 1;
  let found = -1;
  while (low <= high) {
    const middle = (low + high) >> 1;
    if (starts[middle] <= seconds) {
      found = middle;
      low = middle + 1;
    } else {
      high = middle - 1;
    }
  }
  return found;
}
```

```ts
import { ChapterPlayer } from './chapter-player';

const PLAYER_ORIGIN = 'https://www.youtube-nocookie.com';
const WIDGET = { id: 1, channel: 'widget' };

/** Drives a YouTube embed through its iframe API; the frame must be loaded with `enablejsapi=1` (#1808). */
export class YouTubeChapterPlayer implements ChapterPlayer {
  private onPosition: ((seconds: number | null) => void) | null = null;

  private readonly onMessage = (event: MessageEvent): void => {
    if (event.origin !== PLAYER_ORIGIN || event.source !== this.frame.contentWindow) return;
    const seconds = currentTimeOf(event.data);
    if (seconds !== null) this.onPosition?.(seconds);
  };

  private readonly onLoad = (): void => this.post({ event: 'listening', ...WIDGET });

  constructor(private readonly frame: HTMLIFrameElement) {
    window.addEventListener('message', this.onMessage);
    frame.addEventListener('load', this.onLoad);
  }

  playFrom(seconds: number): void {
    this.command('seekTo', [seconds, true]);
    this.command('playVideo', []);
  }

  watch(onPosition: (seconds: number | null) => void): void {
    this.onPosition = onPosition;
  }

  release(): void {
    this.onPosition = null;
    window.removeEventListener('message', this.onMessage);
    this.frame.removeEventListener('load', this.onLoad);
  }

  private command(func: string, args: unknown[]): void {
    this.post({ event: 'command', func, args, ...WIDGET });
  }

  private post(message: object): void {
    this.frame.contentWindow?.postMessage(JSON.stringify(message), PLAYER_ORIGIN);
  }
}

function currentTimeOf(data: unknown): number | null {
  if (typeof data !== 'string') return null;
  try {
    const time = (JSON.parse(data) as { info?: { currentTime?: unknown } } | null)?.info?.currentTime;
    return typeof time === 'number' ? time : null;
  } catch {
    return null;
  }
}
```

```ts
import { presetLocalStorage } from './support/auth';
import { entryDetailJson, entryWire, readerFailedJson, stubOneFeedReader } from './support/reader';
import { silentWav } from './support/audio';

/** #1808: chapters under a video and atop an episode. Every API read is stubbed; the spec owns its data. */
const CHAPTERS = [
  { startSeconds: 0, title: 'Opening' },
  { startSeconds: 20, title: 'Middle' },
  { startSeconds: 40, title: 'Ending' },
];

const VIDEO = entryWire({ id: 1, title: 'A video', url: 'https://www.youtube.com/watch?v=JsBZOcqZerk' });
const EPISODE = entryWire({
  id: 2,
  title: 'An episode',
  url: 'https://fixtures.invalid/episode',
  attachments: [{ url: 'https://fixtures.invalid/episode.mp3', mimeType: 'audio/mpeg' }],
});
const VIDEO_BODY = '<p><a href="https://www.youtube-nocookie.com/embed/JsBZOcqZerk">Watch on YouTube</a></p><p>Thanks</p>';

async function stubArticles(page: Page): Promise<void> {
  await stubOneFeedReader(page, 'Fixture feed');
  await page.route('https://www.youtube-nocookie.com/**', (route) =>
    route.fulfill({ body: '<!doctype html><title>player</title>', contentType: 'text/html' }),
  );
  await page.route('https://fixtures.invalid/**', (route) =>
    route.fulfill({ body: silentWav(60), contentType: 'audio/wav' }),
  );
  await page.route(
    (url) => url.pathname === '/api/entries',
    (route) => route.fulfill({ json: { entries: [VIDEO, EPISODE], nextCursor: null } }),
  );
  await page.route(
    (url) => /^\/api\/entries\/\d+\/reader$/.test(url.pathname),
    (route) => route.fulfill({ json: readerFailedJson('player_page') }),
  );
  await page.route(
    (url) => /^\/api\/entries\/\d+$/.test(url.pathname),
    (route) => {
      const id = Number(new URL(route.request().url()).pathname.split('/').pop());
      if (id === VIDEO.id) return route.fulfill({ json: entryDetailJson(VIDEO, VIDEO_BODY, CHAPTERS) });
      if (id === EPISODE.id) return route.fulfill({ json: entryDetailJson(EPISODE, '<p>Show notes.</p>', CHAPTERS) });
      return route.fallback();
    },
  );
}

test.beforeEach(async ({ page }) => {
  await page.setViewportSize({ width: 1280, height: 800 });

  await page.goto('/?subscription=1');

test('an episode starts at a tapped chapter and the list follows it', async ({ page }) => {
  await page.locator('app-entry-list').getByText('An episode', { exact: true }).click();

  const rows = page.locator('app-article-content .reader-chapters__row');
  await expect(rows).toHaveCount(3);
  await rows.nth(1).click();
```
