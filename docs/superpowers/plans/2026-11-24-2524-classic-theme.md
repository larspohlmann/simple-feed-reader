# Classic Theme Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A second theme, `classic` (ivory paper, Newsreader serif, light and dark), stored as the account preference `theme` and picked in Settings → Preferences; and, in every theme, icons that scale with the text beside them.

**Architecture:** Backend: a `Theme` enum column on `user_reading_settings`, carried by the preferences `PATCH`, `/api/me` and the backup line, exactly as `sidebarStyle` is. Frontend: a palette file beside `_graphite.scss`, selected by a new `data-theme-name` attribute on `<html>` next to `data-theme` (the mode) and `data-brightness`; type differences travel as tokens that graphite leaves undefined, so every consumer reads `var(--token, today's value)` and graphite stays as it renders now. Newsreader ships self-hosted from files whose size and vertical metrics are corrected by a script in the repo. Icon scaling extends the existing `scales-with-text` row class.

**Tech Stack:** Symfony 8.1 / Doctrine (PHP 8.5), Angular 20 standalone + signals, SCSS tokens, Jest, Playwright (Chromium and WebKit are installed), Python 3 with fontTools and brotli (both present on this machine).

**Spec:** `docs/superpowers/specs/2026-11-24-classic-theme-design.md` (issue #2524). The look's reference is the overlay script of the visual round, `classic-spike.js`, kept at `.superpowers/brainstorm/classic-theme/classic-spike.js` (gitignored, this machine); port its values, not its selectors or `!important`s.

## Global Constraints

- Values: `graphite` (default) | `classic`. JSON key `theme`; column `theme VARCHAR(10) DEFAULT 'graphite' NOT NULL`; `localStorage` key `sfr.themeName`; attribute `data-theme-name` (absent means graphite). `data-theme` and `sfr.theme` keep meaning the mode.
- Graphite renders as today. The one intended difference is icon size at a text size other than 100%.
- No component, template or service branches on the theme's name; classic exists only in `src/app/theme/**`, `src/styles/**`, `index.html`'s inline script and the theme-name service. No `!important`.
- An unknown or missing backup value restores as `graphite` (restore over reject), like `sidebarStyle`.
- No request to another origin for fonts. The font files are requested only when classic is on.
- Frontend `.scss` outside `theme/` and `styles/`: tokens only, no hex, no ad-hoc `px`.
- Commit messages `type(#2524): …`, no attribution lines. Every `backend/src` file touched is PHPMD-clean.
- Copy (en / de / fr / es): `settings.theme` "Theme" / "Design" / "Thème" / "Tema"; `settings.themeHint` "Colours and typeface of the whole app." / "Farben und Schrift der gesamten App." / "Couleurs et police de toute l'application." / "Colores y tipografía de toda la aplicación."; `settings.themeSaveFailed` "The theme could not be saved to your account." / "Das Design konnte nicht in deinem Konto gespeichert werden." / "Le thème n'a pas pu être enregistré dans votre compte." / "No se pudo guardar el tema en tu cuenta."; `settings.themeOption.graphite` "Graphite" / "Graphit" / "Graphite" / "Grafito"; `settings.themeOption.classic` "Classic" / "Klassisch" / "Classique" / "Clásico". Check each against the glossary before committing.

## Review Focus

- Sign out of a classic account, sign in to another: the page must be graphite (cache and attribute both cleared) — Task 6 test.
- Brightness step other than 0 under classic: surfaces must come from classic's derived step, not graphite's step block of equal specificity — Task 4 spec, Task 6 e2e.
- A cached `sfr.themeName` that is not a known name (older build, hand-edited): graphite, no attribute — Task 6 test.
- 150% text in a comment's action row: the icon-only delete button's glyph is as tall as Reply's — Task 1 e2e.
- 150% text with a poster avatar standing in for the favicon: it scales with the source name and the kicker stays on one line — Task 1 e2e, and `magazine-kicker-one-line.spec.ts` stays green untouched.
