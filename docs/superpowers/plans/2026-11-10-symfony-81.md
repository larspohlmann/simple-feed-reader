# Symfony 8.1 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the backend to Symfony 8.1 with DoctrineBundle 3 (#2155). Make the IP pin hold across connection reuse,
then give the reader and feed fetches persistent connections and a 5 s connect cap.

**Architecture:** Task 1 is the framework upgrade on its own; nothing else may change behaviour in it.
- Task 2 makes `EgressOptions::pinned()` add a `CURLOPT_CONNECT_TO` entry that targets an alias for the pinned address
  list. curl then reuses a connection only when the pin matches. Task 2 also adds `EgressOptions::merge()`, so a
  caller's `extra` survives the pin's `extra`.
- Task 3 adds the persistent-connection and connect-cap options to the two hot paths.

**Tech Stack:** PHP 8.5, Symfony 8.1, DoctrineBundle 3.3, curl 8.23 (Docker), PHPUnit 12.

**Spec:** `docs/superpowers/specs/2026-11-10-symfony-81-design.md`

## Global Constraints

- The target is `symfony/*` `8.1.*`, not 8.0 and not 8.2.

- `composer update` re-resolves only the `symfony/*` packages, `doctrine/doctrine-bundle` and what they require. No
  unrelated package moves. If `bump-after-update` rewrites an unrelated constraint, revert it (as in #2148).

- [ ] **Step 1: Test helper, the keep-alive server.** Create `backend/tests/Support/keep-alive-server.php`. It is an
  HTTP/1.1 server that keeps connections open and numbers them, so a test can see reuse:

  ```php
  <?php

  declare(strict_types=1);

  // Usage: php keep-alive-server.php <ip> <port> <name>. Answers every request with "<name>#<connection number>".
  [, $ip, $port, $name] = $argv;
  $server = stream_socket_server("tcp://$ip:$port", $errorCode, $errorMessage);
  if (false === $server) {
      fwrite(STDERR, "$errorMessage\n");
      exit(1);
  }
  fwrite(STDOUT, "ready\n");
  $connections = [];
  $connectionCount = 0;
  while (true) {
      $readable = [$server, ...array_values($connections)];
      $unused = null;
      stream_select($readable, $unused, $unused, null);
      foreach ($readable as $socket) {
          if ($socket === $server) {
              $connections[++$connectionCount] = stream_socket_accept($server);
              continue;
          }
          $number = array_search($socket, $connections, true);
          $request = fread($socket, 65536);
          if ('' === $request || false === $request) {
              fclose($socket);
              unset($connections[$number]);
              continue;
          }
          $body = "$name#$number";
          fwrite($socket, "HTTP/1.1 200 OK\r\nContent-Length: " . strlen($body) . "\r\nConnection: keep-alive\r\n\r\n$body");
      }
  }
  ```

  Create `backend/tests/Support/KeepAliveServer.php`, which starts and stops it:

  ```php
  <?php

  declare(strict_types=1);

  namespace App\Tests\Support;

  final class KeepAliveServer
  {
      /** @param resource $process */
      private function __construct(private $process)
      {
      }

      public static function start(string $ip, int $port, string $name): ?self
      {
          $process = proc_open(
              [\PHP_BINARY, __DIR__ . '/keep-alive-server.php', $ip, (string) $port, $name],
              [1 => ['pipe', 'w'], 2 => ['pipe', 'w']],
              $pipes,
          );

              return null;
          }
          if ("ready\n" !== fgets($pipes[1])) {

              return null;
          }

          return new self($process);
      }

      public function stop(): void
      {

          proc_close($this->process);
      }
  }
  ```

- [ ] **Step 4: Implement the pin and the merge** in `EgressOptions`. Replace `pinned()` and delete
  `freshConnectionAfter()`:

  ```php
  /**
   * The `resolve` pin for this family attempt, plus a connect-to alias for exactly these addresses. curl pools
   * connections by host and port, and a pooled connection ignores `resolve`; the connect-to target is part of a
   * connection's identity, so a connection is reused only by a request with the same pin.
   *
   * @return array{resolve: array<string, string>, extra: array{curl: array<int, list<string>>}}
   */
  public static function pinned(GuardedUrlModel $guarded, int $pinAttempt): array
  {
      $pins = $guarded->pinnedAddressAttempts();
      $pinnedAddresses = $pins[min($pinAttempt, \count($pins) - 1)];
      $alias = sprintf('pin-%s.invalid', substr(hash('sha256', $pinnedAddresses), 0, 16));

      return [
          'resolve' => [$guarded->host => $pinnedAddresses, $alias => $pinnedAddresses],
          'extra' => ['curl' => [\CURLOPT_CONNECT_TO => [sprintf('%s::%s:', self::connectToHost($guarded->host), $alias)]]],
      ];
  }

  /**
   * Request options overlaid with egress options; `extra` is merged, not replaced, so a caller's
   * `use_persistent_connections` survives the pin's `extra.curl`.
   *
   * @param array<string, mixed> $options
   * @param array<string, mixed> $egress
   *
   * @return array<string, mixed>
   */
  public static function merge(array $options, array $egress): array
  {
      $merged = [...$options, ...$egress];
      $extra = array_replace_recursive(self::extraOf($options), self::extraOf($egress));
      if ([] !== $extra) {
          $merged['extra'] = $extra;
      }

      return $merged;
  }
  ```

    through.

  ```php
  namespace App\Service\Fetch\Support;

  /**
   * Options for the hot fetch paths: connections, TLS sessions and DNS kept per worker process, and a connect phase
  ```
