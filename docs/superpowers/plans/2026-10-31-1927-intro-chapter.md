# Intro Chapter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A served chapter list whose first chapter starts after 0:00 gets an "Intro" chapter at 0:00 in front.

**Architecture:** `ChapterSequence::fromZero()` prepends the Intro chapter; `ChaptersOnOpen::serve()` applies it to whatever it serves (description chapters of a video or an episode, declared or fetched chapters). Stored chapters stay as the feed declared them.

**Tech Stack:** PHP 8.4, PHPUnit 12.

**Spec:** GitHub issue #1927, "Decided" section.

## Global Constraints

- The Intro chapter is `new EntryChapter(0, 'Intro')`, added only when the list is non-empty and its first chapter starts after 0.
- Applied on serve, never stored.
- Commit format `fix(#1927): summary`, no attribution.

`ChapterSequence`:

```php
    private const string INTRO = 'Intro';

    /**
     * @param list<EntryChapter> $chapters
     *
     * @return list<EntryChapter>
     */
    public static function fromZero(array $chapters): array
    {
        if ($chapters === [] || $chapters[0]->startSeconds === 0) {
            return $chapters;
        }

        return [new EntryChapter(0, self::INTRO), ...$chapters];
    }
```

`ChaptersOnOpen::serve()` becomes a wrapper: the current body moves to a private `chaptersOf(Entry $entry): ServedChaptersModel`, and `serve()` returns `new ServedChaptersModel(ChapterSequence::fromZero($served->chapters), $served->contentHtml)`.
