# Live social counts in the article view (#1615) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Opening a Bluesky or Mastodon post in the article view shows its live like, repost/boost, reply and (Bluesky) quote counts in a right-aligned row below the post. The row's like button replaces the article header's thumbs up. Counts are never stored in the database.

**Architecture:**

- **Backend.** `GET /api/entries/{id}/social` is a thin controller over a new `Service/Social/SocialCounts`. It reads a shared two-minute cache pool first. On a miss it asks the network's public source: a `PostCountsSource/PostCountsSourceInterface` strategy, which is the AppView on Bluesky and the post's origin instance on Mastodon. When that source fails or does not apply, it falls back to the post the user's acting account resolves, through the existing `SocialPostFinder`. Both resolvers now carry the counts they already receive.
- **Like flow.** `SocialLikes` drops the cached counts after a like or an unlike.
- **Entry JSON.** `social` is now set for every post and gains `canLike`.
- **Frontend.** A root `SocialCountsService` (the `CommentsService` pattern) feeds a new `app-social-counts` row, which loads when it scrolls into view. It sits after the link cards and before the categories. The row's like goes through `EntryActionHandler.like`. The displayed like number follows the store's optimistic `isLiked`.

**Tech Stack:** Symfony 7.4 / PHP 8.4, Doctrine ORM 3, symfony/cache (filesystem pool), symfony/rate-limiter, symfony/http-client (`MockHttpClient` via `RoutedHttpClient`), PHPUnit 12; Angular 20 (standalone, signals), Transloco, Jest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-13-1615-social-counts-design.md` (binding). Read it before starting any task.

## Rulings where the spec was silent or the code argued

1. **The fallback.** If the public source fails or does not apply, `SocialCounts` runs `SocialPostFinder::find`.
   - If that throws `NoSocialAccountForNetworkException`, the public failure is rethrown. When no public source applied, that failure is a `SocialNetworkUnreachableException`.
   - Any other fallback failure propagates as is, e.g. `SocialAccountNeedsReconnectException` → its existing `SocialProblems` arm.
   - A fallback answer whose `SocialPostModel::counts` is null is a `SocialNetworkUnreachableException`.
2. **"Does not apply" is `Exception/PostNotPubliclyCountableException`.** `SocialCounts` turns it into a `SocialNetworkUnreachableException` (with the original as `previous`) before the fallback, so it never reaches HTTP. It needs no `SocialInteractionProblems` arm.
3. **Every public failure falls back:** not found, throttled, unreachable and not applicable. The Mastodon origin source maps its answers as follows:
   - `404` → `SocialPostNotFoundException`. A followers-only status reads as 404 to the public, and the acting account may still see it.
   - `401`/`403` → not applicable. An instance that closes its API to anonymous readers answers that way, and `MastodonApiClient::accepted` would otherwise call it a refused credential.
   - `429`/`5xx` → `MastodonApiClient::accepted` handles them.
4. **The Bluesky source honours the AppView host throttle.** While `AppViewClient::isThrottled()` holds, it throws `SocialNetworkThrottledException` (no `Retry-After`) without asking. This is what makes "failures are not cached" safe.
   - It maps `FeedThrottledException` → throttled with its seconds, and any other `FetchException` or `AppViewAnswerException` → unreachable.
   - It takes the one post view the AppView answered rather than looking it up by address, so an AT URI that names its author by handle still counts.
5. **Cache.** The pool's `default_lifetime: 120` is the only TTL; there is no per-item `expiresAfter`.
   - The key is `social_counts.` plus the xxh128 hash of `"{network} {address}"`.
   - A cache hit is returned as is and never re-saved, so a hot post is not kept alive past two minutes.
6. **`SocialLikes` drops the entry only after a like or an unlike succeeds** (after the flush). An idempotent no-op (already liked, never liked) drops nothing.
7. **Entry JSON.** The like-row lookup still runs only for posts on networks the user has an account on. This keeps "one like query per page" and "no like query without an account" (two existing enricher tests).
   - `isLiked` is false for a post the user cannot like.
   - `canLike` = the user has an account on that network.
8. **`likedAtLoad` is the entry's `isLiked` when the counts request is sent.** That is the last state the server's count can include, since a like drops the server cache. The displayed likes are floored at 0.
9. **The counts row is a reading-scope `TrailingPart`** (`joinsFocus: false`), between the link cards and the comments. The reading tail then measures past it, like every other section below the body.
10. **The row mounts inside the reader view's `@if (!source.loading())` block, right after the link cards**, so it appears with the article (spec: "renders as soon as the article does").
11. **Labels.**
    - Keys are `reader.socialCounts.{likes,reposts,boosts,replies,quotes}{One,Other}`, picked through `core/i18n/plural-key.ts`, with the raw count as `{{count}}`.
    - Mastodon's reposts are "boosts". Likes are "likes" on both networks, matching #1600's "Like on Mastodon".
    - Each count is a `role="img"` span carrying `title` and `aria-label`.
12. **A failed counts call (502/503) is reported to `ClientErrorReporter`** by the existing `authInterceptor` (every status ≥ 500), as a failed like already is. It shows no toast; the backend log gets a deduplicated line. The spec chose problem statuses over a 200 status body, so this plan keeps them. Flag it to the user if the log noise matters.
13. **`SocialApiWiring::mastodonApiClient()` becomes public** so the origin source's unit test can build a guarded `MastodonApiClient`. Its guard resolves only `mastodon.example`, so the unit tests use addresses on that host.

  - `409 social_post_unsupported`;
  - `502 social_network_unreachable`;
  - `503 social_network_throttled` with `Retry-After`.

- **Cache pool `social.counts.cache`:** `cache.adapter.filesystem`, **`default_lifetime: 120`**, with a comment above it like its neighbours.

- **Row layout.**

  - Like = accent pill (`--accent`, `--border-strong` rim, `--radius-pill`); liked = filled icon, `--accent` rim, `--accent-soft` background.

```php
<?php

declare(strict_types=1);

namespace App\Service\Social\Model;

/** A post's public counts as its network reports them now; Mastodon has no quotes. */
final readonly class SocialCountsModel
{
    public function __construct(
        public int $likes,
        public int $reposts,
        public int $replies,
        public ?int $quotes,
    ) {
    }

    /** @return array{likes: int, reposts: int, replies: int, quotes: int|null} */
    public function toCacheEntry(): array
    {
        return [
            'likes' => $this->likes,
            'reposts' => $this->reposts,
            'replies' => $this->replies,
            'quotes' => $this->quotes,
        ];
    }

    public static function fromCacheEntryOrNull(mixed $stored): ?self
    {
        if (!\is_array($stored)) {
            return null;
        }
        $likes = $stored['likes'] ?? null;
        $reposts = $stored['reposts'] ?? null;
        $replies = $stored['replies'] ?? null;
        $quotes = $stored['quotes'] ?? null;
        if (!\is_int($likes) || !\is_int($reposts) || !\is_int($replies) || (null !== $quotes && !\is_int($quotes))) {
            return null;
        }

        return new self($likes, $reposts, $replies, $quotes);
    }
}
```

```php
<?php

declare(strict_types=1);

namespace App\Service\Social\Support;

use App\Service\Bluesky\Model\JsonNodeModel;
use App\Service\Social\Model\SocialCountsModel;

final class PostCounts
{
    private function __construct()
    {
    }

    /** The counts of an `app.bsky.feed.defs#postView`; null when one of likes, reposts or replies is missing. */
    public static function ofBlueskyPost(JsonNodeModel $post): ?SocialCountsModel
    {
        $likes = $post->int('likeCount');
        $reposts = $post->int('repostCount');
        $replies = $post->int('replyCount');
        if (null === $likes || null === $reposts || null === $replies) {
            return null;
        }

        return new SocialCountsModel($likes, $reposts, $replies, $post->int('quoteCount'));
    }

    /** The counts of a Mastodon `Status`; null when one of them is missing. */
    public static function ofMastodonStatus(JsonNodeModel $status): ?SocialCountsModel
    {
        $likes = $status->int('favourites_count');
        $reposts = $status->int('reblogs_count');
        $replies = $status->int('replies_count');
        if (null === $likes || null === $reposts || null === $replies) {
            return null;
        }

        return new SocialCountsModel($likes, $reposts, $replies, null);
    }
}
```

```php
namespace App\Service\Social\Support;

/** Where a Mastodon status address's own instance serves the status to anyone: its two address shapes only. */
final class MastodonStatusAddress
{
    private const array STATUS_SHAPES = [
        '~^https://([a-z0-9.-]+)/users/[^/?#]+/statuses/(\d{1,32})$~iD',
        '~^https://([a-z0-9.-]+)/@[^/?#]+/(\d{1,32})$~iD',
    ];

    private function __construct()
    {
    }

    public static function statusApiUrlOrNull(string $address): ?string
    {
        foreach (self::STATUS_SHAPES as $shape) {
            if (1 === preg_match($shape, $address, $parts)) {
                return sprintf('https://%s/api/v1/statuses/%s', $parts[1], $parts[2]);
            }
        }

        return null;
    }
}
```

```php
<?php

declare(strict_types=1);

namespace App\Service\Social\PostCountsSource;

use App\Enum\SocialNetwork;
use App\Service\Bluesky\Model\JsonNodeModel;
use App\Service\Fetch\Model\ApiRequestModel;
use App\Service\Fetch\Model\ApiResponseModel;
use App\Service\Social\Exception\PostNotPubliclyCountableException;
use App\Service\Social\Exception\SocialNetworkUnreachableException;
use App\Service\Social\Exception\SocialPostNotFoundException;
use App\Service\Social\MastodonApiClient;
use App\Service\Social\Model\SocialCountsModel;
use App\Service\Social\Support\MastodonStatusAddress;
use App\Service\Social\Support\PostCounts;
use Symfony\Component\HttpFoundation\Response;

/** Asks the status's own instance, anonymously: the counts every reader of the post sees there. */
final readonly class MastodonOriginCountsSource implements PostCountsSourceInterface
{
    private const array CLOSED_TO_THE_PUBLIC = [Response::HTTP_UNAUTHORIZED, Response::HTTP_FORBIDDEN];

    public function __construct(private MastodonApiClient $mastodon)
    {
    }

    public static function network(): string
    {
        return SocialNetwork::Mastodon->value;
    }

    public function countsOf(string $address): SocialCountsModel
    {
        $statusUrl = MastodonStatusAddress::statusApiUrlOrNull($address)
            ?? throw new PostNotPubliclyCountableException('The address names no status on a Mastodon instance.');
        $answer = self::accepted($this->mastodon->answer(ApiRequestModel::get($statusUrl)));
        $status = JsonNodeModel::of($answer->json());
        if (!\in_array($address, [$status->string('uri'), $status->string('url')], true)) {
            throw new PostNotPubliclyCountableException('The instance answered with another status.');
        }

        return PostCounts::ofMastodonStatus($status)
            ?? throw new SocialNetworkUnreachableException('The instance answered a status without its counts.');
    }

    private static function accepted(ApiResponseModel $answer): ApiResponseModel
    {
        if (Response::HTTP_NOT_FOUND === $answer->status) {
            throw new SocialPostNotFoundException('The post is no longer on its Mastodon instance.');
        }
        if (\in_array($answer->status, self::CLOSED_TO_THE_PUBLIC, true)) {
            throw new PostNotPubliclyCountableException('The Mastodon instance shows its statuses to accounts only.');
        }

        return MastodonApiClient::accepted($answer);
    }
}
```

```php
<?php

declare(strict_types=1);

namespace App\Service\Social;

use App\Service\Social\Model\SocialCountsModel;
use App\Service\Social\Model\SocialPostAddressModel;
use Psr\Cache\CacheItemPoolInterface;
use Symfony\Component\DependencyInjection\Attribute\Autowire;

final readonly class SocialCountsCache
{
    public function __construct(
        #[Autowire(service: 'social.counts.cache')]
        private CacheItemPoolInterface $cache,
    ) {
    }

    public function find(SocialPostAddressModel $post): ?SocialCountsModel
    {
        $item = $this->cache->getItem(self::keyOf($post));

        return $item->isHit() ? SocialCountsModel::fromCacheEntryOrNull($item->get()) : null;
    }

    public function remember(SocialPostAddressModel $post, SocialCountsModel $counts): void
    {
        $item = $this->cache->getItem(self::keyOf($post));
        $item->set($counts->toCacheEntry());
        $this->cache->save($item);
    }

    public function forget(SocialPostAddressModel $post): void
    {
        $this->cache->deleteItem(self::keyOf($post));
    }

    private static function keyOf(SocialPostAddressModel $post): string
    {
        return 'social_counts.' . hash('xxh128', $post->network->value . ' ' . $post->address);
    }
}
```

```php
<?php

declare(strict_types=1);

namespace App\Service\Social;

use App\Entity\Entry;
use App\Entity\User;
use App\Enum\SocialNetwork;
use App\Service\Social\Exception\NoSocialAccountForNetworkException;
use App\Service\Social\Exception\NotASocialPostException;
use App\Service\Social\Exception\PostNotPubliclyCountableException;
use App\Service\Social\Exception\SocialAccountNeedsReconnectException;
use App\Service\Social\Exception\SocialCredentialsRejectedException;
use App\Service\Social\Exception\SocialNetworkThrottledException;
use App\Service\Social\Exception\SocialNetworkUnreachableException;
use App\Service\Social\Exception\SocialPostNotFoundException;
use App\Service\Social\Model\SocialCountsModel;
use App\Service\Social\Model\SocialPostAddressModel;
use App\Service\Social\PostCountsSource\PostCountsSourceInterface;
use App\Service\Social\Support\SocialPostAddress;
use Psr\Container\ContainerInterface;
use Symfony\Component\DependencyInjection\Attribute\AutowireLocator;

/** A post's live counts: from the cache, else its network's public source, else the user's acting account. */
final readonly class SocialCounts
{
    public function __construct(
        private SocialCountsCache $cache,
        private SocialPostFinder $posts,
        #[AutowireLocator('app.social_post_counts_source', defaultIndexMethod: 'network')]
        private ContainerInterface $publicSources,
    ) {
    }

    /**
     * @throws NotASocialPostException
     * @throws SocialPostNotFoundException
     * @throws SocialNetworkThrottledException
     * @throws SocialNetworkUnreachableException
     * @throws SocialAccountNeedsReconnectException
     * @throws SocialCredentialsRejectedException
     */
    public function of(User $user, Entry $entry): SocialCountsModel
    {
        $post = SocialPostAddress::of($entry)
            ?? throw new NotASocialPostException('This entry is not a Bluesky or Mastodon post.');
        $cached = $this->cache->find($post);
        if (null !== $cached) {
            return $cached;
        }

        try {
            $counts = $this->publicCountsOf($post);
        } catch (SocialPostNotFoundException | SocialNetworkUnreachableException $publicFailure) {
            $counts = $this->actingAccountCountsOf($user, $entry, $publicFailure);
        }
        $this->cache->remember($post, $counts);

        return $counts;
    }

    private function publicCountsOf(SocialPostAddressModel $post): SocialCountsModel
    {
        try {
            return $this->publicSourceOn($post->network)->countsOf($post->address);
        } catch (PostNotPubliclyCountableException $exception) {
            throw new SocialNetworkUnreachableException('No public source counts this post.', previous: $exception);
        }
    }

    private function actingAccountCountsOf(
        User $user,
        Entry $entry,
        SocialPostNotFoundException|SocialNetworkUnreachableException $publicFailure,
    ): SocialCountsModel {
        try {
            $resolved = $this->posts->find($user, $entry);
        } catch (NoSocialAccountForNetworkException) {
            throw $publicFailure;
        }

        return $resolved->counts
            ?? throw new SocialNetworkUnreachableException('The network answered the post without its counts.');
    }

    private function publicSourceOn(SocialNetwork $network): PostCountsSourceInterface
    {
        $source = $this->publicSources->get($network->value);
        \assert($source instanceof PostCountsSourceInterface);

        return $source;
    }
}
```

```ts
import { Injectable, Signal, WritableSignal, inject, signal } from '@angular/core';
import { onIdentityChange } from '../../../core/auth/session-identity';
import { SocialCountsDto } from '../../entry-social';
import { EntryDto } from '../../models';
import { ReaderApi } from '../../reader-api';

const CACHE_CAP = 50;
const FRESH_MS = 120 * 1000;
const FAILED_RETRY_MS = 60 * 1000;

export type CountedEntry = Pick<EntryDto, 'id' | 'social'>;

/** `likedAtLoad`: the post's `isLiked` when its counts were asked for; the shown likes count from it. */
export type SocialCountsState =
  | { status: 'idle' }
  | { status: 'loading' }
  | { status: 'ok'; counts: SocialCountsDto; likedAtLoad: boolean; loadedAt: number }
  | { status: 'failed'; failedAt: number };

@Injectable({ providedIn: 'root' })
export class SocialCountsService {
  private readonly api = inject(ReaderApi);
  private readonly states = new Map<number, WritableSignal<SocialCountsState>>();
  private generation = 0;

  constructor() {
    onIdentityChange(() => this.clear());
  }

  state(id: number): Signal<SocialCountsState> {
    return this.stateFor(id).asReadonly();
  }

  load(entry: CountedEntry): void {
    const state = this.stateFor(entry.id);
    if (isStale(state())) this.fetch(entry, state);
  }

  private stateFor(id: number): WritableSignal<SocialCountsState> {
    const state = this.states.get(id) ?? signal<SocialCountsState>({ status: 'idle' });
    this.states.delete(id);
    this.states.set(id, state);
    const oldest = this.states.size > CACHE_CAP ? this.states.keys().next().value : undefined;
    if (oldest !== undefined) this.states.delete(oldest);
    return state;
  }

  private fetch(entry: CountedEntry, state: WritableSignal<SocialCountsState>): void {
    const generation = this.generation;
    const likedAtLoad = entry.social?.isLiked ?? false;
    state.set({ status: 'loading' });
    this.api.socialCounts(entry.id).subscribe({
      next: (counts) => {
        if (generation === this.generation) {
          state.set({ status: 'ok', counts, likedAtLoad, loadedAt: Date.now() });
        }
      },
      error: () => {
        if (generation === this.generation) state.set({ status: 'failed', failedAt: Date.now() });
      },
    });
  }

  private clear(): void {
    this.generation++;
    this.states.clear();
  }
}

function isStale(state: SocialCountsState): boolean {
  switch (state.status) {
    case 'idle':
      return true;
    case 'ok':
      return Date.now() - state.loadedAt >= FRESH_MS;
    case 'failed':
      return Date.now() - state.failedAt >= FAILED_RETRY_MS;
    default:
      return false;
  }
}
```

```ts
  });
```

```ts
  constructor() {
    effect((onCleanup) => onCleanup(this.loadOnSight(this.entryId())));
  }

  protected format(count: number): string {
    return this.compact().format(count);
  }

  protected labelKey(kind: CountKind, count: number): string {
    return pluralKey(`reader.socialCounts.${kind}`, count);
  }

  private loadOnSight(id: number): () => void {
    const host = this.host.nativeElement;
    const scroller = this.scroller();
    const observer = new IntersectionObserver(
      ([sighting]) => {
        if (sighting?.isIntersecting) this.service.load({ id, social: this.entry().social });
      },
      { root: scroller, rootMargin: prefetchMargin(scroller.clientHeight) },
    );
    observer.observe(host);
    return () => observer.disconnect();
  }
}
```

```ts
import { expect, Page, Route, test } from '@playwright/test';
import { presetLocalStorage } from './support/auth';
import {
  entryDetailJson,
  entryWire,
  readerFailedJson,
  stubOneFeedReader,
} from './support/reader';

/**
 * #1615: a social post's article ends in a right-aligned row of its live
 * counts, the like last; the article header offers no second thumbs up. Every
 * API read is stubbed, so the spec owns the counts it asserts on.
 */
const POST = entryWire({
  id: 1,
  title: 'A post worth counting',
  social: { network: 'bluesky', isLiked: false, canLike: true },
});

type CountsAnswer = Parameters<Route['fulfill']>[0];

async function stubPost(page: Page, counts: CountsAnswer): Promise<void> {
  await stubOneFeedReader(page, 'Fixture feed');
  await page.route('**/api/client-errors', (route) => route.fulfill({ status: 204 }));
  await page.route(
    (url) => url.pathname === '/api/entries',
    (route) => route.fulfill({ json: { entries: [POST], nextCursor: null } }),
  );
  await page.route(
    (url) => url.pathname === '/api/entries/1',
    (route) =>
      route.request().method() === 'GET'
        ? route.fulfill({ json: entryDetailJson(POST, '<p>The post itself.</p>') })
        : route.fallback(),
  );
  await page.route(
    (url) => url.pathname === '/api/entries/1/reader',
    (route) => route.fulfill({ json: readerFailedJson() }),
  );
  await page.route(
    (url) => url.pathname === '/api/entries/1/social',
    (route) => route.fulfill(counts),
  );
  await page.route(
    (url) => url.pathname === '/api/entries/1/like',
    (route) => route.fulfill({ json: { isLiked: route.request().method() === 'PUT' } }),
  );
}

async function openPost(page: Page) {
  await page.setViewportSize({ width: 1280, height: 800 });
  await presetLocalStorage(page, { 'sfr.layout': 'pane' });
  await page.goto('/?subscription=1');
  await page.locator('app-entry-list').getByText(POST.title, { exact: true }).click();
  const view = page.locator('app-reader-view');
  await expect(view.locator('.content p')).toHaveText('The post itself.');
  return view;
}

test('the counts sit right-aligned below the post, the like last and live', async ({ page }) => {
  await stubPost(page, { json: { likes: 41, reposts: 5, replies: 7, quotes: 2 } });
  const view = await openPost(page);

  const row = view.locator('app-social-counts .row');
  await expect(row.locator('.count .number')).toHaveText(['5', '7', '2']);
  const like = row.locator('button.like');
  await expect(like.locator('.number')).toHaveText('41');
  expect(await row.evaluate((element) => element.lastElementChild?.matches('button.like'))).toBe(
    true,
  );
  const rowBox = (await row.boundingBox())!;
  const likeBox = (await like.boundingBox())!;
  expect(Math.abs(rowBox.x + rowBox.width - (likeBox.x + likeBox.width))).toBeLessThanOrEqual(1);
  await expect(view.locator('app-entry-actions.actions')).not.toContainText('thumb_up');

  await like.click();

  await expect(like.locator('.number')).toHaveText('42');
  await expect(like).toHaveAttribute('aria-pressed', 'true');
});

test('a post whose counts fail keeps its like button and shows no numbers', async ({ page }) => {
  await stubPost(page, {
    status: 502,
    contentType: 'application/problem+json',
    body: JSON.stringify({
      type: 'social_network_unreachable',
      title: 'The network could not be reached',
      status: 502,
    }),
  });
  const view = await openPost(page);

  const like = view.locator('app-social-counts button.like');
  await expect(like).toBeVisible();
  await expect(like.locator('.number')).toHaveCount(0);
  await expect(view.locator('app-social-counts .count')).toHaveCount(0);
});
```
